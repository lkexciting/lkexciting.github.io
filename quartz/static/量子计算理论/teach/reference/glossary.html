术语与核心公式

一页纸的压缩知识：术语对照、必背矩阵、必背公式。放在手边，做推导时随时回查。所有定义以课件 01–03 为准，符号与之后每节课一致。

一、量子术语 ↔ 线性代数术语

这门课的核心约定：量子力学的语言，就是线性代数。看到左边的词，立刻在脑子里换成右边的操作。

量子力学术语线性代数含义
态矢量 (State Vector)向量
本征态 (Eigenstate)特征向量
本征值 (Eigenvalue)特征值
右矢 |a⟩（ket）列向量
左矢 ⟨a|（bra）行向量（|a⟩ 的共轭转置）
内积 ⟨a|b⟩标量；a†b
外积 |a⟩⟨b|矩阵（秩 1，投影矩阵的基本单元）
算符 (Operator)矩阵
线性算符线性变换
酉算符（幺正算符）酉矩阵：U U† = I
厄米算符厄米矩阵：H = H†
基态 (Ground State)本征值最小的本征态
叠加原理线性组合性质
投影算符 Pi = |ei⟩⟨ei|投影矩阵
记住这两句

只有酉矩阵才能表示量子门；只有厄米矩阵才能表示可观测量（可测量的物理量）。

三、必背公式

1. 态与归一化

|ψ⟩ = α|0⟩ + β|1⟩，　α, β ∈ ℂ
⟨ψ|ψ⟩ = |α|2 + |β|2 = 1

测得 0 的概率 p(0)=|α|2，测得 1 的概率 p(1)=|β|2。

2. 内积与正交

⟨φ|ψ⟩ = φ†ψ，　⟨φ|ψ⟩ = 0 ⟺ 两态正交

3. 叠加基

|+⟩ = 1√2(|0⟩ + |1⟩)，　|−⟩ = 1√2(|0⟩ − |1⟩)

⟨+|−⟩ = 0，且两者都归一化，所以它们也是一组标准正交基。

4. 张量积（多比特）

|a⟩ ⊗ |b⟩ = (a1b, a1b2, a2b1, a2b2)T

n 个量子比特的态是 2n 维单位复向量。能写成单个张量积的态叫可分态，否则叫纠缠态。

5. 四个贝尔态

|Φ±⟩ = 1√2(|00⟩ ± |11⟩)，　|Ψ±⟩ = 1√2(|01⟩ ± |10⟩)

制备方法：|00⟩ → 对 q1 施加 H → 再以 q0 为控制施加 CNOT，得到 |Φ+⟩。

6. 投影测量

p(i) = ⟨ψ|Pi|ψ⟩ = |⟨ei|ψ⟩|2，　坍缩后 |ψ′⟩ = Pi|ψ⟩ / √p(i)

平均值 ⟨A⟩ = ⟨ψ|A|ψ⟩；方差 ΔA = √(⟨A2⟩ − ⟨A⟩2)。

7. 量子傅里叶变换（QFT）

|j⟩ → 1√N Σk=0N−1 e2πijk/N |k⟩，　N = 2n

电路只由 H 门与受控相位旋转门构成，门数 O(n2)；输出比特顺序与张量积形式相反，末尾需要 SWAP。

四、常用恒等式（化简 Oracle 时会用到）

H2 = IH 门做两次等于没做
H X H = Z共轭变换：把 X 换成 Z
H Z H = X反过来也成立
X2 = Y2 = Z2 = I泡利门各自平方为恒等
X = H Z H与上式等价，常用于"把 X 换成 Z"
H = i Ry(π/2) Rx(π)H 的旋转分解（课件 01 · P40）

使用方式：推导时先写"基矢 + 列向量"，再套矩阵乘法，最后用归一化/正交做自检。80% 的考试推导题都能用这三步走完。
