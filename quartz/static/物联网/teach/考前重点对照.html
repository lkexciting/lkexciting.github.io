★★ 计算节点寿命 T = C / I（低功耗与节能）已掌握

小课 0001 · 八点五节
三步模板（考试直接套）
1️⃣ 平均电流 I = 工作电流×占空比 + 休眠电流×(1−占空比)
2️⃣（有自放电时）漏电流 I_漏 = C×自放电率 ÷ 24h，加进 I
3️⃣ T = C ÷ I（小时），÷24 换成天
课件例题重算：2800mAh，工作 20mA、休眠 0.5mA
占空比 10%：I = 20×10% + 0.5×90% = 2 + 0.45 = 2.45mA → T = 2800÷2.45 ≈ 1142h（课件答案一致）
变式 占空比 1%：I = 20×1% + 0.5×99% = 0.695mA → T ≈ 4029h ≈ 168 天
再叠加自放电 0.5%/天：I_漏 = 2800×0.5%÷24 ≈ 0.583mA → I = 1.278mA → T ≈ 2190h ≈ 91 天

第 4 章边缘智能

📖 小课 0401–0406 🗂 速查卡：边缘智能

★★★模型量化（×号 = 全清单唯一大重点）已掌握

小课 0403
  • 本质：通过特定映射函数把高精度浮点数（FP32）映射为低精度整数，减少存储、内存与计算开销
  • 存储位宽表（必背）：
数据类型位宽字节数表示范围
FP32（单精度浮点）32 位4 Byte—
Int8（量化）8 位1 Byte有符号 −128 ～ 127
Int4（极致量化）4 位0.5 Byte有符号 −8 ～ 7
例题重算（直接由上表推出）
FP32 → INT8：4 Byte → 1 Byte，存储压缩 4 倍；FP32 → INT4：4 Byte → 0.5 Byte，压缩 8 倍。
例：400 MB 的 FP32 模型量化为 INT8 后 = 400 × (1/4) = 100 MB；量化为 INT4 后 = 400 × (1/8) = 50 MB。
  • 课件关联案例：DeepSeek-R1-Distill-Qwen-7B 的 GGUF 文件对比（量化档位越小文件越小）

★★剪枝：非结构化与结构化已掌握

小课 0404
  • 老师笔记小字 = 课件的两大分类：非结构化剪枝与结构化剪枝（按剪枝粒度分类）
  • 与量化对照记忆：剪枝是删除冗余参数，量化是降低数值精度——都在同一模型内部操作

★★蒸馏：教师-学生模型与核心概念已掌握

小课 0405
  • 老师笔记小字"两个模型、核心（思想）"= 教师模型（大而准，例 DeepSeek-R1 671B）指导 学生模型（小而快，例 DeepSeek-R1-Distill-Qwen-7B）训练
  • 课件"蒸馏核心概念"= 四个：教师模型、学生模型、硬标签（真实标注/独热编码）、软标签（教师输出的概率分布，含"暗知识"）
  • 目的：能力迁移、降低学生部署成本；代价：训练/数据生成成本增加，学生能力受容量与数据限制

第 5 章低功耗无线通信协议

📖 小课 0501–0509 🗂 速查卡：通信协议

★★ 计算① 有效数据率：实际 vs 最大已掌握

小课 0501
  • 最大数据率：802.15.4 = 250kbps，BLE = 2Mbps
  • 802.15.4 发送前主动退避（initialbackoff ∈ (0, CWinit]，CWinit ≈ 10ms），实际数据率一般为最大数据率的 1/3
公式（课件原文）
η = 数据载荷传输时间 ÷ (退避时间 + 包头传输时间 + 数据载荷传输时间)
R_real = η × R
快速估算：802.15.4 实际 ≈ 250kbps × 1/3 ≈ 83.3kbps

★★ 计算② 802.15.4 物理层：DSSS + O-QPSK 时间计算已掌握

小课 0502
  • DSSS：每 4 bit 数据 → 32 位码片（查表扩频）
  • Chip rate = 2M chip/s → data rate = 250kb/s
  • O-QPSK：码片分奇/偶两相位，每相位 chip rate = C/2 = 1M chip/s；每个码片持续 1μs；两相位半码片偏移 0.5μs
例题重算：验证 250kbps
每 4bit 符号 = 32 码片；总速率 2M chip/s → 每符号时间 = 32 ÷ 2M = 16μs
数据率 = 4bit ÷ 16μs = 250 kb/s ✓（与课件一致）

★★ 计算③ LoRaWAN 参数表计算（Chirp 调制）已掌握

小课 0509
  • BW：带宽，中国取 125kHz，美国可取 125kHz 和 500kHz
  • SF：spreading factor，一个 chirp 表示 SF 个 bits，取值 7–12
  • 频率偏移等价于时间偏移；数据由起始频率 offset 调制
公式 + 例题重算（课件原文）
Ts = 2^SF ÷ BW（一个 chirp 的发送时间）
SF=8、BW=125kHz：Ts = 2⁸ ÷ 125000 = 256/125000 s = 2.048ms
课件案例：SF=8、BW=125kHz 发送 [0, 0, 50] → 频率偏移等价时间偏移 0/256Ts、0/256Ts、50/256Ts（2⁸=256）
并发性：同一信道 6 个用户选 6 个不同 SF，相互正交可并发传输

★★ 简答④ 简答大题：6LoWPAN / BLE / LoRaWAN / 功耗已掌握

  • 6LoWPAN 两个主要技术 = 分段重组 + 头部压缩 → 小课 0504

★★ 计算云边计算卸载（老师写"是图"，图+计算都备）已掌握

小课 0607
  • 比较原则：同一任务完成时间；输入上传、网络往返、计算都计入；忽略项先明确
  • 临界判据：若 E ≤ L + C，则云端不可能更快
课件例题重算：D=2Mbit，L=30ms，C=10ms，E=100ms（忽略排队重传）
云端总时间 = D/R + L + C
R=20Mbit/s：100+30+10 = 140ms > E=100ms → 边缘更快 ✓
R=50Mbit/s：40+30+10 = 80ms < 100ms → 云端更快 ✓
阈值：D/R + L + C = E → R = D/(E−L−C) = 2Mbit ÷ 60ms ≈ 33.3 Mbit/s（阈值处两路径时间相同）
画图准备：Greengrass V2 云边协作结构（组件/消息/缓存部署到现场，按端到端时延选择云边分工）——会默画。
