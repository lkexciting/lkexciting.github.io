认证、传输安全与隐私保护

一句话：口令/设备认证怎么验、TLS 和 MQTT 怎么加密、身份与位置隐私怎么藏——TLS 两层结构是本节必考点。

考试内容以 PPT（课件）为准。本课对应课件《第八章-v2(2)》第 2 节"安全机制4：认证与传输安全"和"安全机制5：隐私保护"【教材 PPT 补充单独标注】。原始课件：D:\学习文件\大三上\物联网技术基础与应用开发\第八章-v2(2).pdf

一、认证：口令认证与设备认证

1.1 基于口令的用户认证（盐值 + 散列值）

注册：用户提供用户名和口令 → 系统生成一个随机数（盐值，salt）→ 口令连同样值通过散列函数（Hash function）打乱混合，变为固定长度的散列值（Hash values） → 散列值和盐值分别存放于系统数据库中。

登录：用户提供用户名和口令 → 系统按用户名找到对应散列值和盐值 → 在口令上加对应盐值再散列产生新散列值 → 比较原散列值与新散列值：相等则口令正确，反之错误。

1.2 设备认证（两种）

基于三元组（阿里云 IoT）

三元组是平台授权颁发的设备身份信息，每个设备全球唯一，指 ProductKey、DeviceName、DeviceSecret 的组合。设备建立连接时通过 DeviceSecret 加签设备信息，平台对加签信息进行验证，完成设备登录 IoT 平台。

基于射频指纹

背景：攻击者可以建立一个伪 AP，其 ID 和真实 AP 一样。方法：使用无线射频指纹（如功率放大器非线性指纹结合帧间时间分布指纹），准确鉴别真实 AP 与伪 AP。

二、传输安全：TLS 与安全版 MQTT

2.1 TLS 协议

  • 前身为 SSL（secure sockets layer，安全套接层）协议；在传输层对网络连接进行加密，提供机密性和完整性保障。
  • 广泛用于 Web 应用程序与服务器通信：明文传输的 HTTP 加上 SSL 协议后变成 HTTPS。
  • 一大优势：独立于应用程序之外，高层协议如 HTTP、FTP 等都能透明地运行在 TLS 之上；相比 SSL 能提供更大的灵活性。
  • 两层协议：低层 = 记录协议，为各种高层协议提供基本安全服务；高层 = 握手协议、改变密码标准协议和警报协议，用于管理 TLS 交换。

TLS 握手协议四阶段（必背）：① 客户端发起，建立安全功能并初始化逻辑连接——发 client_hello，服务器回 server_hello；② 服务器向客户端传递建立连接所需信息：证书、密钥信息、证书请求，发完发 server_hello_done；③ 客户端向服务器发送证书、密钥信息和证书验证；④ 根据第 2、3 阶段交换的信息实现密码组合的交换，建立双方安全连接，完成握手。握手协议可使服务器和客户端相互验证并协商加密 MAC 算法及加密密钥。

2.2 安全版 MQTT

MQTT 参与设备分三种身份：发布者、代理、订阅者——代理往往由服务器充当，发布者和订阅者往往是客户端。MQTT 在多层上采取安全措施：

层次安全措施（课件原文）
应用层MQTT 协议提供设备的标识符和密码，以识别认证每个设备
传输层加密认证基于 TLS 协议：单向加密认证只需服务器提供证书；双向加密认证需要客户端和服务器一起提供证书
网络层代理、发布者和订阅者之间的连接支持专线或者 VPN 等传输方式，专用物理或虚拟线路提高网络传输安全性

三、隐私保护：身份隐私与位置隐私

隐私通常指个人不愿公开的私事或秘密。常见隐私问题：身份隐私泄露——用户的身份和其他重要信息关联起来；位置隐私泄露——用户的位置和能唯一确定身份的信息关联起来。

身份隐私保护：假名技术

医疗报销案例：用户 A 有两个假名 Alice 和 Amy，分别用于和医生和保险公司交互。① A 先用假名 Alice 在医院医生处开具诊断凭证；② 再以假名 Amy 把诊断凭证交付给保险公司。保险公司可验证凭证的真实性、有效性与合法性，正常报销；但 A 未向任何实体出具真实身份信息，不泄露任何身份隐私；医院无法确定 A 与假名的关联性，保险公司也无法将 Alice 和 Amy 关联。

位置隐私保护：假位置技术

位置信息含两种形式：标识信息（个体静态特征或属性，可唯一确定个体）与位置信息（个体的位置、行踪或轨迹）。保护方法：保护标识信息——请求服务时只提供位置信息、隐藏标识信息（匿名和假名技术）；保护位置信息——提供混淆或不精确的位置（如假位置信息、路标位置信息）。假位置技术：用户给服务提供者发送多个位置，仅一个真实、其余虚假；提供者为每个位置计算反馈（用户可据反馈正常工作），但攻击者不知哪个是真实位置。

教材 PPT 补充

身份匿名是身份隐私保护的热点方向，知名匿名凭证系统有 Idenmix（IBM）、Primelife、U-Prove。其他认证技术：基于令牌（典型为智能卡 IC card，交互含复位应答 ATR、协议类型选择 PTS 等步骤）；基于生物特征（静态：指纹、手部几何形状、面部特征；动态：步态、动作、行为）。安全传输加密算法 SM4：分组对称密码算法，分组长度 128bit、密钥长度 128bit，加密算法与密钥扩展算法均采用 32 轮非线性迭代结构，S 盒可灵活替换。基于密码的挑战-应答认证协议：用户传身份 U → 主机返回随机数 r → 用户返回 f(r', h(P')) → 主机与模板 f(r, h(P(U))) 比较判断合法性。

课件思考题（本课相关）

1. TLS 协议由哪两层协议组成？各自的作用是什么？

点开看参考答案

由两层协议组成：低层协议——记录协议，为各种高层协议提供基本的安全服务；高层协议——握手协议、改变密码标准协议和警报协议，用于管理 TLS 交换。（课件"安全机制4——TLS"原文）

2. 简述假名系统医疗报销案例：为什么保险公司能正常报销，却不泄露用户的身份隐私？

点开看参考答案

用户 A 用假名 Alice 在医生处开具诊断凭证，再以假名 Amy 将诊断凭证交付给保险公司。保险公司可以验证该诊断凭证的真实性、有效性和合法性，所以可进行正常报销业务；但由于 A 未向任何实体出具自己的真实身份信息，因此不会泄露任何身份隐私——医院无法确定 A 与假名之间的关联性，保险公司也无法将假名 Alice 和假名 Amy 进行关联。（课件"安全机制5——身份隐私保护"原文）
