一、定义与分类（0601）

考点要点
与传统云的区别（5 条）轻量与异构连接 · 设备状态管理 · 时序数据处理 · 设备安全认证 · 并发消息与计算
参与者（3 类）通信运营商（SIM/资费/运维）· 设备制造商（身份/固件/设备服务）· 云与应用厂商（数据分析/业务应用）；能力可组合
CMP网络连接与 SIM 卡管理；示例 Jasper/DCP/GDSP、移动 OneLink、联通 ControlCenter、天翼物联；共享单车：查在线状态/网络定位/流量
DMP设备全生命周期与运行状态管理；示例 海尔 U+、美的云、BOSCH IoT Suite、根云
AEP帮开发者快速构建部署应用（工具/中间件/业务逻辑引擎/API）；示例 AWS IoT、IBM Watson、阿里云 IoT、涂鸦智能
BAP把海量数据转化为业务价值（预测性/可认知）；示例 Predix、Azure IoT、MindSphere
判断题钩子四类并非相互排斥，一个平台可提供多类服务

二、MQTT（0602）

考点要点
报文顺序CONNECT/CONNACK → SUBSCRIBE/SUBACK（登记主题过滤器）→ PUBLISH 分发；发布者不需知道订阅者地址
通配符+ 匹配一个层级；# 匹配多个层级且只在过滤器末尾；发布主题不能含通配符
QoS 0/1/2至多一次（无确认，可能缺失，开销低）/ 至少一次（确认重发，可能重复）/ 恰好一次（额外交互与状态，避免同次交换重复）
两段连接设备→Broker 与 Broker→看板是两次交付；下行 QoS 不高于订阅要求；协议交付 ≠ 业务动作执行一次
吞吐公式QoS1 理想吞吐上界 ≈ C / RTT（C=在途上限）。例：C=20、RTT=80ms → 250 条/s；W=20、RTT=100ms → 200 条/s ≈ 200 KB/s（每条 1KB）
选择依据缺失容忍度、重复后果、时效、资源开销：持续温度→QoS0；重要告警→QoS1；严格交付→QoS2
三协议对比（教材 PPT）MQTT：TCP、代价小、多播、需 Broker；CoAP：UDP、代价小、无中间代理、32+8B；HTTP：TCP、代价大、824+32B（温度上传示例）
延伸Sparkplug 3.0（2022）/ISO/IEC 20237:2023 工业语义互通；MQTT over QUIC 探索连接迁移（标准 3.1.1 基于 TCP）；亿咖通 200 万+ 车辆/在线 35 万+

三、设备管理与 OTA（0603）

考点要点
管理内容生命周期（注册/删除）· 状态（online–offline）· 固件版本 · 固件更新；属性：deviceId/status→生命周期，connectionState→状态，version→版本，updateList→固件更新
设备影子desired（期望）/reported（上报）分存，相等即同步；离线先改 desired，重连取最新目标；幂等目标状态适合影子；一次性动作（投药）不能只留最终状态，短期命令应有有效期
直接控制 vs 影子直接控制=请求响应、需立即确认、离线无效、不保证排序；影子=离线可设、保证指令排序（习题 5：红/蓝灯例子）
OTA 闭环启动上报版本 → 判断升级 → 下载升级包 → 升级后上报版本；版本号启动时上报，不周期循环；差分包：基线相符才能套用、校验→重建→验证、失败可回退
OTA 安全（必背）95% 未保护升级包内容；90% 防不了中间人；61% 可被强制降级；对策：签名校验、双向认证、升级包加密、通讯安全防护
固件验证摘要（内容是否改变）≠ 签名（可信发布者）；写入备用分区→试启动→确认→标记成功（双分区保留恢复路径）

四、IFTTT 与规则引擎（0604）

考点要点
四大问题规则冲突 · 实时性 vs 能耗 · 公平性 · 应用逻辑与执行操作耦合
冲突两条件① IF 条件能同时成立（转 SAT/SMT，Z3 求解；SMT=SAT 推广，含实数/整数/数组）② THEN 同一设备且动作冲突
实时性 vs 能耗自适应查询间隔（接近阈值缩小、远离扩大）；增强语法 WITH time<60 and missratio<0.01（RT-IFTTT，RTSS 2017）
公平性优先级、配额与公平调度约束执行频率；耦合性→规则引擎（筛选消息→转发时序库/函数计算/推送/ML）
控灯案例 Topic 拆分① 安全（限订阅防敏感信息）② 降低耦合（隔离设备）③ 可扩展性（规则引擎变更格式转发）
边界推演−40～125℃ 闭区间；>30 过热；缺失值不作正常值

五、时序数据库与流计算（0605）

考点要点
规模数字1 万设备×1 点/s×16B（8B 时间戳+8B 浮点）→ 8.64 亿点/天 = 13.824 GB/天；近 10 分钟：单设备 600 点/全部 600 万点
InfluxDBtag 标识筛选序列（基数要控制），field 存测量值；写入 precision=s；Flux：range→filter→mean；2.x TSM/Flux ≠ 3.x 列式
Gorilla 压缩记录差异不存完整值，精度不变；5 点 40B→23B（省 42.5%）；固定值 144B / 规则缓变 1465B / 随机噪声 6767B（1000 点、原 8000B）
容量估算数值 8B→2B：字段省 75%，整条记录只省 6/32=18.75%（时间戳 8B+其它 16B 不随同比下降）；压缩后 10B/点
滑动均值直接算法 O((n−k+1)·k)、每窗 k−1 次加法；增量 O(n)、初始化后每点 2 次加减；两者空间均 O(k)（环形缓冲，不能只留总和）
状态规模n=10000,k=1000：8,991,999→18,999 次加减；每设备窗口 8k B，10 万设备 ≈ 0.8 GB
滑动最大值双端队列存候选下标：队首过期移除、新值淘汰队尾较小者；每下标至多进出队一次 → O(n)/O(k)
FlinkkeyBy(device) 隔离状态；框架管分区/调度/托管状态/恢复，算法仍自己实现；Flink 2.0（PVLDB 2025）状态存算分离，290GB 负载 16→8 CU（1CU=1 核+4GB+20GB 盘）

六、安全认证（0606）

考点要点
共享密钥HMAC 验来源与完整性（不等于加密载荷）；认证数据含标识/时间戳/随机挑战；防重放需独立新鲜性检查；风险：任一端密钥泄露
X.509 / PKI私钥签名+公钥认证；证书三种获取：CA 颁发/平台生成/第三方工具；双向 TLS：验服务器证书→交客户端证书→证私钥持有→再查主题权限（连接认证 ≠ 任意授权）
IBC设备标识（序列号/网络地址）+系统参数定公钥；KGC 申请私钥加密传送；减少证书传输
权限身份认证→权限策略→授权执行；权限落到具体操作与资源（如仅允许 Publish 设备 A 温度主题）

七、无服务器计算（0606）

考点要点
冷启动账单冷调用 10+50+350+40=450 ms；热调用 10+40=50 ms；额外准备 400 ms；初始化越长、业务越短影响越显著
环境复用顶层语句（读配置/建 SDK 对象）只在初始化执行；日志：冷=INIT→INVOKE→REPORT；Duration=执行、Init Duration=初始化、Billed=计费口径
优化取舍100 次调用 10 次冷：从头平均 90 ms；SnapStart（恢复 60ms）平均 56 ms；保温 50 ms 但驻留成本（0.5GiB×60s=30 GiB·s）；SnapStart 与预置并发不能同启
部署代码包+配置（Handler/Runtime python3.12/MemorySize 256/Timeout 3）；Lambda 链路 IoT Core→Lambda→SNS

八、边缘计算（0607）

考点要点
Greengrassnucleus + 组件（采集/EdgeAlarm/MQTT Bridge）；recipe=版本+文件+生命周期；本地 IPC 权限与云端 IoT 策略分别配置；业务处理不等待云端往返
计算卸载边缘 ≈ E + D/R；若 E ≤ L+C 云端不可能更快；例 D=2Mbit/L=30/C=10/E=100：20Mbit/s 边缘快、50Mbit/s 云端快
断网缓存50KB/s×4h=720MB（预算需更大）；600MB 预算≈12000s≈3h20m；满盘策略：背压/丢最旧/降采样
补传净清理=上传−产生=500−200=300 条/s；清空 10000 条≈33.33s；event_id 贯穿重传；业务确认后才删 outbox
采集解码bigendian+有符号 16 位+比例 0.1：0x00FD=253→25.3℃；协议适配必须保留数据语义
