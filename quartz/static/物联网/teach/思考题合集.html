Q004简答 / 概念 0001-物联网概述

Q005计算 / 证明 0001-物联网概述

问 ① ：电池 2800mAh，工作 20mA、休眠 0.5mA，占空比 1%，节点工作时长为？

点开看参考答案
I = 20mA×1% + 0.5mA×99% = 0.2 + 0.495 = 0.695mA T = C/I = 2800mAh / 0.695mA ≈ 4029h（约 168 天）

方法与课件例题（占空比 10% → 2.45mA → 1142h）完全一致，只换代入值。

Q006计算 / 证明 0001-物联网概述

Q008计算 / 证明 0002-物联网硬件平台

问 ② ：占空比为 80% 时，谁的能耗低？

点开看参考答案

80% = 8s 工作 + 2s 睡眠：E(F2618) = 2×3.3×10⁻⁶ + 8×1.5×10⁻³ = 0.012 J；E(F5437) = 2×5.1×10⁻⁶ + 8×0.84×10⁻³ = 0.0067 J → F5437 能耗低（工作占主导，比工作功率）。（课后习题答案原解）

Q009计算 / 证明 0002-物联网硬件平台

问 ③ ：占空比为 0.1% 时，谁的能耗低？

点开看参考答案

0.1% = 0.01s 工作 + 9.99s 睡眠：E(F2618) = 9.99×3.3×10⁻⁶ + 0.01×1.5×10⁻³ = 4.7967×10⁻⁵ J；E(F5437) = 9.99×5.1×10⁻⁶ + 0.01×0.84×10⁻³ = 5.9349×10⁻⁵ J → F2618 能耗低（睡眠占主导，比睡眠功率）。

结论口诀：占空比高比"工作功率"，占空比低比"睡眠功率"。

Q024计算 / 证明 0002-物联网硬件平台

Q026对比 0301-操作系统概述与构成

课后习题 1：物联网操作系统与传统操作系统的不同，有什么作用？（课件思考题同款）

点开看参考答案

不同体现在四方面：①操作系统类型数量不同——传统平台基本统一（PC 端 Windows/Linux，手机端 iOS/Android），物联网操作系统仍百家争鸣（Android Things、Windows 10 IoT Core、mbed OS、AliOS-Things、Huawei-LiteOS 等），未建立统一应用生态，移植性较差；②存储空间占用不同——传统 OS 内存占用大（Linux 几百 MB、Windows 几 GB），物联网 OS 一般只有几十 KB（TinyOS 2.x 最小数据内存 2KB、程序闪存 17KB；AliOS-Things 最小数据内存 20KB、程序闪存 40KB），可节省内存资源、提高运行效率；③内存管理方式不同——传统 OS 运行在具有 MMU 的设备上、能提供地址翻译和内存保护，物联网 OS 运行在缺乏 MMU 的设备上时难以提供，可能带来安全问题和运行效率问题；④OS 特权模式不同——传统 OS 运行在有特权模式的 CPU 上、可保护硬件资源安全，物联网芯片多无特权模式、所有指令都能访问任何硬件资源，提高可扩展性但可能有安全问题。

作用有四条：屏蔽物联网碎片化特征、提供统一编程接口；培育物联网生态环境；降低物联网应用开发的成本和时间；为物联网统一管理奠定基础。（课后习题答案原文）

Q096对比 0801-物联网安全概述与攻击

故障注入攻击和侧信道攻击有何异同？

点开看参考答案

相同点：都在于硬件加密过程中的信息泄露，通过这种泄露来推测密钥。

区别：故障注入攻击是通过引入外部因素（例如电磁注入等）来改变硬件的计算逻辑，导致硬件运行出现错误，泄露系统敏感信息；侧信道攻击是通过硬件运行过程中泄露的物理量（例如泄露的电磁波等）来破解密钥。（教材课后习题答案第 2 题原解）

Q097简答 / 概念 0802-硬件安全机制

1. 简述导致物联网设备出现硬件安全的原因。

点开看参考答案

物联网设备拥有大量传感器和控制器，采集的物联网数据会通过硬件的方式被恶意篡改，而硬件防护难以实施：一方面，不同企业根据产品需求和特性进行定制化的裁剪和开发，造成物联网设备与系统间巨大差异性，硬件安全防护方案很难直接移植至物联网中；另一方面，物联网中大量采用的开源组件或项目缺乏安全防护，却没有有效的对应策略或措施。因此物联网设备的硬件安全问题越来越难以解决。（教材课后习题答案第 1 题原解）

Q098对比 0802-硬件安全机制

2. 物理非克隆函数是什么？为什么建立物理非克隆函数？它与信任根的区别是什么？

点开看参考答案

是什么：PUF 是在晶圆制造过程中于芯片内创建的具有独特物理性质的模块，为半导体器件提供唯一的身份标识；具有不可复制性——即使使用相同工艺和材料重新创建相同的 IC，生成的 PUF 也不同，因此非常安全并具有防篡改能力。

为什么建立：为物联网设备提供保护，通常 PUF 密钥作为主密钥，对会话密钥、应用口令等进行加密处理，保证数据安全。

与信任根的区别：两者都用于对数据加密、确保设备安全。区别在于：PUF 使用半导体器件的"指纹"作为密钥进行数据加密，信任根使用硬件安全模块来生成密钥；且 PUF 生成的密钥在系统启动时重新生成、不存储在闪存中，而信任根在硬件安全模块中生成密钥，该模块无法在计算机生态系统之外访问。（教材课后习题答案第 3 题原解）

Q099简答 / 概念 0803-软件与系统安全

1. Potd 蜜罐由哪几部分构成？它们的作用分别是什么？

点开看参考答案

Potd 蜜罐由重定向器、协议进程、监视器三个子模块构成。重定向器和协议进程构成诱饵环境，为攻击者提供入侵的通信接口：重定向器在接收到 TCP 连接请求后将其转发至协议进程子模块并限制会话的数量，保护蜜罐免受 DDoS 攻击；协议进程子模块初始化协议子进程，根据应用层通信协议在子进程中实现相应的协议，将该子进程与 TCP 连接转发至监视器。监视器是蜜罐的监控模块，用于采集攻击者威胁数据并维护蜜罐的安全——监视器对沙盒进行初始化，并在伪终端下搭建 TCP 处理器，TCP 连接与传输将在沙盒中进行，以确保蜜罐的安全。（教材课后习题答案第 5 题原解）

Q103简答 / 概念 0804-无线安全机制

点开看参考答案
