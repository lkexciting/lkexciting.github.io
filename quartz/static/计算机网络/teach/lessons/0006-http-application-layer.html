LESSON 06

应用层与 HTTP

这节课只解决一个问题：浏览器和服务器怎样用 HTTP 对话？

一、应用层协议规定什么

应用层协议规定通信双方交换的消息类型、语法、字段含义和交互顺序。HTTP 规定浏览器如何请求资源、服务器如何返回资源。

二、HTTP 请求与响应

浏览器发送请求，例如 GET /index.html；服务器返回响应，包含状态码、首部和可选的正文。常见状态码包括 200（成功）、301/302（重定向）、404（资源不存在）和 500（服务器错误）。

记忆方法

请求是“我要什么”，响应是“结果怎样 + 内容是什么”。

三、客户—服务器结构

客户端主动发起请求，服务器持续等待并响应多个客户端。服务器通常拥有固定地址或域名，客户端可以临时上线。
