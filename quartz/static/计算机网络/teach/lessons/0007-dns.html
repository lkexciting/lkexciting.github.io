LESSON 07

DNS 与域名解析

这节课只解决一个问题：浏览器怎样把 www.example.com 找到对应的 IP 地址？

一、DNS 做什么

DNS（域名系统）把人类容易记忆的域名映射为 IP 地址。浏览器访问网站前，通常先查询 DNS，得到服务器地址，再建立后续连接。

二、分层的名字空间

DNS 采用层次结构：根域名服务器、顶级域（如 .com、.cn）服务器、权威域名服务器。递归解析器可以代替客户端逐级查询，并缓存结果。

一句话

DNS 像互联网的电话簿：域名方便人记，IP 地址方便网络转发。

三、缓存的作用

解析结果会在客户端、浏览器、操作系统或递归解析器中缓存。缓存能减少查询时间和 DNS 流量，但记录过期前可能暂时保留旧地址。
