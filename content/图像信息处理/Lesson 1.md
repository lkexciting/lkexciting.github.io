# 数字图像处理：表示、任务与基本方法

## 1. 数字图像是什么

二维图像可以写成 $f(x,y)$：位置决定一个像素，像素值表示亮度、颜色或其他测量量。数字图像对空间位置采样、对测量值量化，因此最终存成有限大小的数组。

灰度图常用一个标量表示每个像素；RGB 彩色图通常用三个通道表示。通道数、每通道位深与图像尺寸共同决定原始数据量，文件格式还可能加入元数据、调色板和压缩。

例：1920×1080 的 RGB 图，每通道 8 bit，不压缩像素数据为 $1920\times1080\times3=6,220,800$ B，约 5.93 MiB。这不等于任意 JPEG 或 PNG 文件的大小。

## 2. 从采集到理解的处理链

```text
物理场景 → 成像与采样 → 数字图像 → 校正／增强 → 分析／识别 → 展示或决策
                           └──────── 压缩、存储、传输 ────────┘
```

| 任务 | 输入与输出 | 要解决的问题 |
|---|---|---|
| 图像获取 | 光、电磁或声学信号 → 像素 | 曝光、对焦、采样、重建 |
| 校正与增强 | 图像 → 更合适的图像 | 白平衡、对比度、去噪、去雾 |
| 复原 | 退化图像 → 对原图的估计 | 根据模糊、噪声等退化模型恢复 |
| 几何处理 | 图像 → 坐标变换后的图像 | 拼接、畸变校正、配准 |
| 压缩 | 像素或系数 → 更短编码 | 降低存储和传输成本 |
| 理解 | 图像 → 标签、框、掩码等 | 分类、检测、分割、识别 |

图像处理常产生另一幅图像，计算机视觉更强调从图像中推断场景信息；两者共享很多方法，不能按某个单一算法机械划界。

## 3. 增强与复原的区别

增强强调让图像更适合观察或后续任务，例如拉伸对比度。复原强调利用成像模型估计退化前的信息，例如已知运动模糊核时反卷积。看上去更锐不代表更接近真实，也不保证识别准确率更高。

## 4. 几何变换、拼接与渐变

- Warping：改变像素对应的空间位置，如旋转、缩放、透视校正。
- Panorama：估计多幅图的对应关系，把它们映射到共同坐标系，再进行接缝与亮度融合。
- Morphing：同时改变几何对应与颜色，生成两幅图之间平滑变化的中间帧。

变换一般会落到非整数坐标，因此必须指定插值方式。最近邻简单但易出现块状边缘；双线性利用周围像素插值，会带来一定平滑。

## 5. 存储与传输不能只比后缀

JPEG 通常采用有损压缩，适合自然照片；PNG 采用无损压缩，适合需要精确保留像素或透明信息的图像。BMP 常见的是未压缩位图，但具体变体也可能支持压缩。文件大小取决于尺寸、内容、编码参数与元数据，不能背成“某格式永远只有多少 KB”。

对医学影像、遥感、文本截图等任务，压缩造成的细节损失可能影响测量或识别，选择指标时应考虑最终用途。

## 6. 不同成像方式记录不同物理量

可见光成像记录可见光的反射或发射；红外成像涉及特定红外波段的辐射；X 射线成像利用穿透与吸收差异；超声成像利用声波传播与回波。它们都能形成数组，但像素含义和噪声模型不同，不能无条件复用同一种校正方法。

## 7. 自测

1. 同一幅图缩放后为什么需要插值？——新像素对应的位置可能不落在原来的采样点上。
2. 为什么“视觉更漂亮”不保证更适合识别？——增强可能改变真实纹理、增加伪影，评价应与任务一致。
3. 分辨率相同的两张图为什么可能大小不同？——通道、位深、压缩和图像内容都可能不同。
