LESSON 10

Shor 算法

Shor 算法是量子优势最著名的代表作：它能在多项式时间内完成大数分解，从而威胁 RSA 这类非对称加密。它的量子部分其实只做一件事——用量子相位估计"计算阶"（order finding），其余步骤都是经典计算。内容来自课件 03 · P3（P37–P49）。

一、为什么分解大数很重要

非对称加密（如 RSA）用一对密钥：公钥 \((n, e)\) 可公开，私钥 \((n, d)\) 自留。加密 \(C = a^{e} mod n\)，解密 \(a = C^{d} mod n\)（课件 03 · P38–P41）。其安全性建立在：知道 n 却难以分解出 p、q（课件 03 · P42）。

经典试除法要尝试小于 \(\sqrt{n}\) 的所有因数，复杂度 \(O(\sqrt{n})\)，对大 n 几乎不可行（课件 03 · P43）。Shor 的关键思路：只要能分解 n，就能算出 \(\phi(n)\)，进而算出私钥 d（课件 03 · P42）。

二、用到的数论

Shor 的数论工具

同余 / 阶：\(a\) 模 \(n\) 的阶是使 \(a^{r} \equiv 1 (mod n)\) 成立的最小正整数 \(r\)，记作 \(ord_{n}(a)\)（课件 03 · P38）。
欧拉函数：\(\phi(n)\) 是与 n 互质且小于 n 的正整数个数；若 \(gcd(a,n)=1\) 则 \(a^{\phi(n)} \equiv 1 (mod n)\)（欧拉定理）。
RSA：\(n=pq \Rightarrow \phi(n)=(p-1)(q-1)\)；取 \(e\) 与 \(\phi(n)\) 互质，\(d \equiv e^{-}^{1} (mod \phi(n))\)。

三、Shor 算法流程

随机取一个小于 n 且与 n 互质的正整数 \(a\)，算法如下（课件 03 · P44）：

Shor 主流程

① 量子计算 \(r = ord_{n}(a)\)（核心，用 QPE 做阶查找）；
② 若 \(r\) 为奇数 → 失败，重选 a；
③ 取 \(x = a^{r/2} mod n\)；若 \(x+1 \equiv 0 (mod n)\) → 失败，重选 a；
④ 否则 \(p = gcd(x-1, n)\)，\(q = gcd(x+1, n)\) 即为 n 的非平凡因子。

关键事实（课件 03 · P44）：只有"计算阶"这一步用到量子计算，其余全部是经典计算。也就是说，Shor 把一个难问题（分解）归约到了一个量子擅长的问题（在叠加态上估计周期/阶）。

四、量子部分：阶查找 = 相位估计

定义模幂酉变换 \(U\)（满足 \(U|x\rangle = |a^{x} mod n\rangle\)），以及本征态 \(|u_{s}\rangle\)（课件 03 · P45–P46）。性质表明：\(|u_{s}\rangle\) 是 U 的本征态；而 \(|1\rangle\) 恰好是所有 \(|u_{s}\rangle\) 的等概率叠加态——因此我们可以直接对 \(|1\rangle\) 做 QPE 而无需专门制备 \(|u_{s}\rangle\)（课件 03 · P46–P47）。

对 \(U\) 与 \(|1\rangle\) 运行 QPE，会等概率测得相位 \(0, 1/r, 2/r, \ldots, (r-1)/r\)（课件 03 · P47）。把测得的小数还原成分数，取分母的最小公倍数即得 \(r\)（课件 03 · P48）。

例题（课件 03 · P48）：取 \(a=7, n=15\)，已知 \(r=4\)，QPE 输出相位为 \(0, 0.25, 0.5, 0.75\)。把 0.25→1/4、0.5→1/2、0.75→3/4，取分母最小公倍数即得 \(r=4\)。反之，若已知这些小数却不知 r，正是 Shor 要反推的部分。

U 算子的初级构造（课件 03 · P49）：穷举 \(x=0\ldots N-1\)，对每个 x 算 \(f(x)=a^{x} mod N\)，写出 \(|x\rangle\to|f(x)\rangle\) 的矩阵并求和，即得 U 的矩阵表示。
