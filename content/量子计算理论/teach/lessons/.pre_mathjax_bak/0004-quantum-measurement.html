LESSON 04

量子测量

前三课管"态怎么写、怎么演化"。这一课管"真正去读一个量子系统会得到什么"。核心是 Born 规则（概率从哪来）、投影测量（怎么算概率和坍缩态），以及单/双比特怎么测。注意：测量是非线性坍缩，和前面酉矩阵的线性演化是两回事（课件 02 · P7）。

演化与测量的分工（课件 02 · P6–P7）：不测量时，系统按薛定谔方程做线性、幺正演化（时间演化算符 U 一定是幺正的）；一旦测量，系统非线性、随机地坍缩到被测可观测量的某个本征态。作用量子门 = 线性演化；测量 = 坍缩。

一、Born 规则：概率从哪来

对量子比特 |ψ⟩ = α|0⟩ + β|1⟩ 测量，只能得到 0 或 1：以 |α|2 的概率得 0，以 |β|2 的概率得 1，且 |α|2+|β|2=1（课件 02 · P19）。

测量有多种形式（课件 02 · P19）：一般测量、投影测量（projective）、POVM 测量。本课聚焦投影测量，它是量子线路里最常用的。

二、投影测量：可观测量与谱分解

投影测量由一个可观测量 A（厄米矩阵）描述。把 A 做谱分解（课件 02 · P21）：

A = Σᵢ λᵢ Pᵢ

其中 λᵢ 是特征值（可能的测量结果），Pᵢ 是对应特征空间的投影算子。测得结果 i 的概率为：

p(i) = ⟨ψ|Pᵢ|ψ⟩，　测量后态坍缩为 Pᵢ|ψ⟩ / √p(i)

可观测量平均值 E[A] = ⟨ψ|A|ψ⟩，标准差 ΔA = √(⟨A²⟩−⟨A⟩²)（课件 02 · P21）。

三、投影算子的三条性质

投影算子集合 {Pₖ} 满足（课件 02 · P16、P22）：

投影算子公理

① Pₖ² = Pₖ（幂等）；② PₖPⱼ = 0 (k≠j)（两两正交）；③ Σₖ Pₖ = I（完备性）。
几何意义：把态投影到各特征向量方向再按特征值线性组合（课件 02 · P18）。

四、单比特测量

对 |ψ⟩ = α|0⟩+β|1⟩，投影算子为 P₀=|0⟩⟨0|、P₁=|1⟩⟨1|（课件 02 · P23）：

p(0) = ⟨ψ|P₀|ψ⟩ = |α|²，　坍缩后态为 |0⟩
p(1) = ⟨ψ|P₁|ψ⟩ = |β|²，　坍缩后态为 |1⟩

两者自伴、满足完备性 P₀+P₁=I。

五、线路里的测量门

真实量子计算机最后要对末态测量才能拿到结果，所以测量也作为量子线路的一部分，称为测量门（课件 02 · P25）。在计算基下，测量门的矩阵形式就是投影算子；量子线路图里用带仪表符号的门表示。

六、示例：单比特线路测量

课件 02 · P26 的标准例子：|0⟩ 先过 H 门 → (|0⟩+|1⟩)/√2，再测量。由单比特公式：

p(0) = |1/√2|² = 1/2，　p(1) = |1/√2|² = 1/2

所以测得 0 和 1 各 1/2 概率，坍缩后分别为 |0⟩、|1⟩。

七、双比特测量：整体测 vs 部分测

整体测量（课件 02 · P27–P29）：对态 |ψ⟩ 用 Mₓᵧ = |xy⟩⟨xy| 测，得到结果 xy 的概率为 ⟨ψ|Mₓᵧ|ψ⟩，之后坍缩到 |xy⟩。例如若 |ψ⟩ 在 |01⟩ 上的振幅为 0，则测得 01 的概率为 0，态不可能坍缩到 |01⟩。

部分测量（课件 02 · P30–P31）：只测其中一个比特，另一个比特保持相干。测得 0/1 的概率由对"被忽略比特"求和得到，测量后整体态被相应地投影。

八、量子态区分公设

测量还能用来区分量子态（课件 02 · P32）：

可区分性

正交的态向量：可对每个 |ψᵢ⟩ 定义测量算子 Mᵢ=|ψᵢ⟩⟨ψᵢ|，确定性区分。
非正交的态：可以证明不存在任何测量能精确区分它们（因为非正交态可分解为平行+正交分量，测量概率 p₂<1）。
