LESSON 08

量子傅里叶变换（QFT）

经典里有离散傅里叶变换（DFT），把信号从时域变到频域。量子傅里叶变换（QFT）是它的量子版本：把计算基 |j⟩ 映射到"频域基"，把振幅序列 x_j 变成 y_k。它自身是一个重要算符，更是后面 QPE、Shor 算法的核心子模块。内容来自课件 03 · P1（P6–P24）。

一、从 DFT 到 QFT

离散傅里叶变换（DFT）是把离散信号从时域转换到频域的数学工具；逆变换（IDFT）反之（课件 03 · P1）。QFT 的作用正是将量子态从计算基 |j⟩ 映射至频域基 |k⟩，使振幅序列 x_j 经变换变为 y_k。标准定义为：

QFT|j⟩ = (1/√N) Σ_{k=0}^{N-1} e^{2πi jk/N} |k⟩，其中 N = 2ⁿ

QFT 不只是 DFT 的量子实现，更是 QPE、Shor 等众多量子算法的子模块（课件 03 · P7）。

二、二进制记法

为分析 n 比特下的 QFT 电路，课件规定（课件 03 · P8）：

  • 基态 |j⟩ 写成二进制 |j_{n-1}…j_0⟩，其中 j = 2^{n-1}j_{n-1} + … + 2⁰j_0。
  • 用 0.j_0 j_1 … j_{n-1} 表示二进制小数 j_0/2 + j_1/4 + … + j_{n-1}/2ⁿ。
  • 用 n 个量子比特做 QFT 时，共有 N = 2ⁿ 个基态。

基于这套记法，QFT 算符可写成张量积形式，便于据此构建电路并证明其幺正性（课件 03 · P8–P13 给出逐步证明：展开频域基 → 指数求和拆入张量积 → 交换求和与张量积顺序 → 利用 e^{2πi m}=1 略去整数部分）。

三、单比特与双比特情形

单比特：对计算基 |0⟩,|1⟩ 作用 QFT 后，由矩阵形式可知单比特 QFT 等于 H 门（课件 03 · P14–P15）。即对 |ψ⟩=α|0⟩+β|1⟩，QFT 给出 (|α+β⟩ + (α−β)|1⟩)/√2，正是 H 的效果。

双比特：QFT 需要 H 门配合受控旋转门 R₂（课件 03 · P16）。

QFT 电路要点

① 电路只用 Hadamard 门和受控旋转门；所有门都是酉的，因此 QFT 本身是酉变换；
② 验证过程：对第 1 个比特加 H → 得到 |0⟩+e^{2πi·0.j_{n-1}}|1⟩，再依次对其余比特施加受控旋转，最终得到一串形如 |0⟩+e^{2πi·0.j_{n-1}…j_0}|1⟩ 的张量积；
③ 电路末端的态与张量积形式顺序相反，再加一系列 SWAP 门即可对齐（课件 03 · P18–P22）；
④ 双比特 QFT 电路：H → 受控 R₂ → H → SWAP（课件 03 · P23–P24）。

复杂度：观察电路可知，QFT 的量子门复杂度为 O(n²)（课件 03 · P23）。相比经典 DFT 的 O(N log N)=O(n 2ⁿ)，这是指数级的加速潜力来源之一。

易错点：QFT 电路输出端需要 SWAP 把比特顺序翻回来，否则得到的是"反序"的频域态。这是手写 QFT 电路时最容易漏掉的一步。
