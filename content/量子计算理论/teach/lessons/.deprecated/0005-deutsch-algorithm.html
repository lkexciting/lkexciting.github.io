LESSON 05

Deutsch 算法：一次查询判定函数类型

经典要查两次才知道一个 1 比特函数 f:{0,1}→{0,1} 是"常量"还是"平衡"；量子用一次 Oracle 调用就确定。这一课把前面所有工具（H、X/Z、CNOT、测量、相位反冲）串成一个完整算法，亲手跑一遍，你就拿到了期中考试那道必考题的满分模板。

课件笔误提醒（务必记牢）：课件 01 · P64 原文写"测得 |0⟩ 说明 f 是平衡函数"，但同一页的推导给出第一比特末态为 |f(0)⊕f(1)⟩，标准结论应为 0 → 常数函数，1 → 平衡函数。考试按推导走，别照抄那句错话。

一、问题：1 比特函数的两类

函数 f:{0,1}→{0,1} 只有四个，分两类：

  • 常量（constant）：f(0)=f(1)。即 f(x)=0 或 f(x)=1。
  • 平衡（balanced）：f(0)≠f(1)。即 f(x)=x 或 f(x)=1−x。

经典算法最坏要查 f(0) 和 f(1) 两次才能区分。目标：量子只调一次 Oracle U_f 就判定类型。

一句话

Deutsch 算法 = 一次查询，判定 f 是常量还是平衡。这是"量子加速"的第一个干净例子。

二、Oracle U_f 与相位反冲

Oracle 是"黑盒"，把 f 编码进比特翻转：

U_f |x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩

关键技巧：把第二比特初态设为 |−⟩ = (|0⟩−|1⟩)/√2，而不是 |1⟩。因为 |−⟩ 有个妙性质：翻一次就变号，X|−⟩ = −|−⟩。于是

U_f |x⟩|−⟩ = (−1)f(x) |x⟩|−⟩

看！f 的值从"比特是否翻转"变成了"第一比特上的相位 ±1"。这一步叫相位反冲（phase kickback，相位反冲），是几乎所有量子算法的核心套路：把"答案"藏进相位，后面让相位自己干涉出来。

三、完整线路与推导

初态 |0⟩|1⟩，两个比特各来一个 H，得到 |+⟩|−⟩；上 U_f；最后对第一比特再上 H（第二比特不用管了）：

|0⟩|1⟩ →H⊗H |+⟩|−⟩ →U_f 1√2((−1)f(0)|0⟩ + (−1)f(1)|1⟩) ⊗ |−⟩ →H⊗I 测第一比特

最后一步 H 作用在 α|0⟩+β|1⟩ 上（这里 α=(−1)^{f(0)}, β=(−1)^{f(1)}）得到

12(α+β)|0⟩ + 12(α−β)|1⟩
  • 常量：α=β → α−β=0 → 第一比特必为 0。
  • 平衡：α=−β → α+β=0 → 第一比特必为 1。

于是只测第一比特：得 0 → 常量，得 1 → 平衡。全程只调了一次 U_f！下面模拟器让你四种 f 都跑一遍。

四、HXH = Z 在哪起作用

第 2 课你手推过 HXH = Z：把一个 X（比特翻转）"夹"在两层 H 中间，就变成 Z（相位翻转）。本算法的最后一步 H 正是这个角色的放大版——它把 U_f 在 |+⟩|−⟩ 上制造的相位模式，转换到计算基里可读的 0/1。

H|x⟩ = 1√2(|0⟩ + (−1)x|1⟩)

直觉：H 是"傅里叶基变换"，把相位的奇偶变成幅度。常量时两个相位相同（偶），干涉全 constructive → 0；平衡时相位相反（奇），干涉全 destructive → 1。经典计算机做不到这种"先全体叠加、再整体干涉"。

五、为什么重要 / 推广到 Deutsch–Jozsa

把 1 比特推广到 n 比特：Deutsch–Jozsa 算法用一次查询判定 f 是常量还是平衡，而经典最坏要 2^{n−1}+1 次——指数级加速。所有知名算法的骨架都一样：

  1. 叠加：用 H 把输入铺成全体叠加；
  2. 编码：用 Oracle 把答案藏进相位（相位反冲）；
  3. 干涉：用 H（或 QFT）把相位变幅度；
  4. 测量：读出一个经典比特，完成判定。

后面的 Shor（求阶→QPE）和 Grover（搜索）都是这个四步骨架的变体。
