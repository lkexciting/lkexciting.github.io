LESSON 04

测量与偏迹

前三课管"态怎么写、怎么演化"。这一课管"真正去读一个量子系统会得到什么"：Born 规则给每个结果的概率，测量让态坍缩，偏迹把"我看不到的那个比特"的边缘态算出来。最后一节用偏迹给出"纠缠"最严谨的定义——它正好补上你期中考试要用的那块拼图。

一、Born 规则：测量基上的概率

对单比特态 |ψ⟩ = α|0⟩ + β|1⟩，在标准基 { |0⟩, |1⟩ } 下测量，得到的结果是 0 或 1，概率分别是振幅模平方：

p(0) = |α|²，　p(1) = |β|²

这是量子力学的公理，不是推导出来的。归一化 |α|²+|β|²=1 保证两者加起来必为 1（总概率守恒）。推广到多比特：测到计算基 |x⟩ 的概率 = |⟨x|ψ⟩|²，就是该基矢对应振幅的模平方。

一句话

读一个比特，结果是 0 或 1，概率各自等于对应基矢振幅的模平方 |振幅|²。这就是 Born 规则。

二、投影测量与坍缩

标准基测量可以用投影算符写干净：P₀ = |0⟩⟨0|，P₁ = |1⟩⟨1|。期望值（多次平均）

⟨P₀⟩ = ⟨ψ|P₀|ψ⟩ = |α|²

关键是坍缩：一旦测出结果 j，系统不再是原来的叠加态，而瞬间变成对应的本征态 |j⟩（标准基下）。所以测得 0，态就变成 |0⟩；此时再测一次，必然还是 0——因为已经没有叠加了。

易错且关键：测量不是"读出已有的值"，而是"逼系统亮出一个本征态"。叠加态在测量前没有确定的 0/1 值，是测量这个动作本身产生了结果。把量子比特当成"藏着一个 0 或 1 的硬币"是考场上最常见的丢分点。

三、双比特测量：纠缠怎么被发现

单独测贝尔态 |Φ⁺⟩ = (|00⟩+|11⟩)/√2 的第一个比特：

p(第一比特=0) = 1/2，　p(第一比特=1) = 1/2

但真正神奇的是关联：如果第一比特测得 0，第二比特必定是 0；第一比特测得 1，第二比特必定是 1。两者 100% 锁定，与距离无关。这不是"事先约定好谁是谁"（经典关联也能部分做到），而是测量瞬间强制产生。下面这个模拟器让你亲手看到锁定过程：

四、偏迹：把看不到的比特"边缘化"

当系统是两个比特、你只能观测其中一个时，需要一种"把另一个比特求和掉"的运算——偏迹（partial trace，偏迹/部分迹）。先写密度矩阵：纯态 ρ = |ψ⟩⟨ψ|，双比特态是 4×4。对 |Φ⁺⟩：

ρ = |Φ⁺⟩⟨Φ⁺| = 1/2001/2000000001/2001/2

它怎么算出来的：把 |Φ⁺⟩ 写成列向量 v = (1/√2, 0, 0, 1/√2)T，密度矩阵就是外积 ρ = v·v†——第 (i, j) 个格子等于 vi × vj（这里全是实数，共轭不改变数值）。v 只有第 1、4 位非零（各 1/√2），相乘只在四角出 1/√2 × 1/√2 = 1/2，其余格子撞上 0，全为 0——于是得到上面那个"只有四角是 1/2"的 4×4 矩阵。

偏迹 Tr₂[ρ]（对第二比特求迹）得到第一比特的约化密度矩阵 ρ₁（2×2）。按定义逐元素求和，结果是：

ρ₁ = Tr₂[ρ] = 1/2001/2 = 12I

逐格子验算（2×2 分块，对角线两块相加、非对角线两块相加）：

ρ₁[0][0] = 12 + 0 = 12，　ρ₁[1][1] = 0 + 12 = 12，　ρ₁[0][1] = ρ₁[1][0] = 0

用你的 Python 功底验算（考试仍要手写）：

import numpy as np
psi = np.array([1, 0, 0, 1]) / np.sqrt(2)      # |Φ⁺⟩ 的列向量
rho = np.outer(psi, psi)                       # 外积 = 密度矩阵，四角 1/2
rho1 = np.trace(rho.reshape(2, 2, 2, 2), axis1=1, axis2=3)  # 偏迹掉第二比特
print(rho1)                    # [[0.5 0. ] [0.  0.5]] = I/2
print(np.trace(rho1 @ rho1))   # 0.5 < 1 → 混合态 → 纠缠

直觉：整个系统明明是纯态（完全确定），但只看一个比特却是"最大不确定"的 I/2——信息全藏在两个比特的关联里，不在单个比特上。这正是纠缠的标志。

约化矩阵 I/2 叫"最大混合态"。它的平方 (I/2)² = I/4，迹 Tr[(I/2)²] = 1/2 < 1。这个 Tr[ρ₁²] < 1 是后面判纠缠的硬指标。

五、纠缠的严格定义（偏迹版）

把第 3 课"写不成乘积态就是纠缠"换成密度矩阵的严格说法：

  • 可分纯态：能写成 |ψ⟩⊗|φ⟩。此时 Tr₂[|ψψ⟩⟨ψψ|] = |ψ⟩⟨ψ| 仍是纯态（秩 1，Tr[ρ₁²]=1）。
  • 纠缠态：偏迹后变成混合态（秩 2，Tr[ρ₁²] < 1）。
纯双比特态纠缠 ⇔ Tr[(Tr₂ ρ)²] < 1

这条是"第 3 课 ad−bc=0 判据"的密度矩阵升级版：乘积态偏迹仍纯，纠缠态偏迹变混合。考场上两种判法都要会，看题目给的是振幅还是密度矩阵。

判据（考试双保险）

双比特纯态：ad−bc=0 或 Tr[(Tr₂ρ)²]=1 → 可分；否则纠缠。
