# Copy Ctor
- **copying**
	- **拷贝构造函数** 是一种特殊的构造函数，它用于**创建一个新对象，并将其初始化为一个同类型已存在对象的副本**。通俗地说，就是用另一个对象来“拷贝”出一个新对象。
	- **基本语法**
		```cpp
		class MyClass 
		{
			public:
			    // 拷贝构造函数的典型声明
			    MyClass(const MyClass& other); // 参数通常是 const 引用
		};
		```
	- **关键特征：**
		1. 函数名与类名相同。    
		2. 没有返回值。    
		3. 参数**必须是**对**同类对象**的引用（通常是 `const` 引用）。    
		    - **为什么必须是引用？** 如果不是引用，那么在传参时，为了调用拷贝构造函数，需要复制实参，而这个复制过程本身又需要调用拷贝构造函数……这就形成了一个无限的递归调用链，导致编译错误。
	- **拷贝是通过==拷贝构造函数==实现的**    
		- **具有唯一的签名：`T::T(const T&);**    
		    - 显式参数使用 **常量引用** 传递        
		- **如果你没有提供拷贝构造函数，C++ 会自动为你生成一个！**    
		    - 它会 **拷贝每个成员变量**        
		        - 对于基本类型（数字）、其他对象、对象数组，这是可行的。            
		    - 它会 **拷贝每个指针**        
		        - **问题：** 新旧对象的指针成员将指向 **同一块内存**，数据因此被共享！
	- **包含指针的时候怎么办呢？**
		- **方案一：仅拷贝指针（浅拷贝）**
			- **行为：** 只复制指针本身的值（内存地址），而不复制指针所指向的内存块。    
			- **后果：**    
			    - 多个对象中的指针成员指向 **同一块动态分配的内存**。        
			    - 当一个对象被析构并释放了这块内存后，其他对象的指针就变成了 **悬空指针**。        
			    - 当第二个对象也被析构并再次尝试释放同一块内存时，会导致 **未定义行为**，通常是程序崩溃。
		-  **方案二：拷贝整个数据块（深拷贝）**
			- **行为：** 为新对象的指针成员 **重新分配** 一块新的、大小足够的内存，然后将原对象指针所指向的 **所有数据** 复制到这块新内存中。    
			- **后果：**    
			    - 每个对象都拥有自己独立的、完整的数据副本。        
			    - 对象之间互不影响，析构时也能安全地释放各自的内存，避免了重复释放的问题。
