# 物联网技术基础与应用开发 · Glossary

本课程规范术语表。用词以**课件与指定教材**为准；术语在你掌握后持续补充与收紧。

## 课程框架

**端–管–云**：
本课程的主线技术体系。端=设备侧（硬件/OS/端侧 AI），管=通信协议，云=云平台；第 7 章做云-端一体，第 8 章讲安全。
_Avoid_：用"四层模型"替代本课程口径。

**典型物联网应用架构**：
终端感知设备 → 无线接入（BLE/NB-IoT/WiFi/GPRS）→ 网关 → 互联网 → 物联网云平台 → 客户端。

**网关（Gateway）**：
无线接收设备数据，再通过有线方式回传到云平台的中间节点。

**物联网云平台**：
存储感知数据，提供查询/分析/处理/展示，管理终端与网关接入，并提供多重安全防护。

## 第 1 章概念

**物联网（课件定义）**：
物理设备及嵌入了电子器件、软件、传感器的物件组成的网络；物件具有感知、计算、连接能力，把物理世界集成到数字世界。

**AIoT**：
人工智能赋能物联网（AI + IoT），对应物联网 3.0 阶段（2020 至今）。

**垂直一体化**：
软硬件、网络与云平台耦合在一起、难以复用与标准化的开发架构（课件列为挑战 3）。

**低代码开发**：
以少量代码快速搭建应用的开发方式；课件作为应对"开发链长"的机遇。

**边缘计算**：
在靠近物或数据源头的网络边缘侧，融合网络、计算、存储、应用能力，就近提供智能服务；可降传输、降延迟、增隐私。

**RFID**：
由有源阅读器与若干无源标签构成的射频识别系统，用于身份识别、供应链、仓储等。

**普适计算（Pervasive Computing）**：
强调任何时间、地点都可计算，特别关注用户行为与所处环境（上下文）的感知。

**节点生命周期**：
T = C / I（C 电池容量，I 平均电流）；占空比下 I = 工作电流×占空比 + 休眠电流×(1−占空比)。

## 第 2 章概念

**三类硬件平台**：
类 PC 嵌入式设备（≈1 亿台，Intel Core，ATM/零售服务点）；智能物件（≈8 亿台，Cortex-A/Atom，PLC/边缘网关）；物件（≈90 亿台，MCU，温度传感器/智能灯泡）。

**CPU / MCU / MPU**：
CPU=运算和控制核心；MCU=CPU+内存+I/O+时钟电路集成于一个芯片，低功耗、适合电池供电；MPU=侧重高性能计算与复杂任务，时钟更快、内存更大。

**RAM / Flash**：
RAM 存数据、易失性；Flash 存程序、非易失性（断电后程序仍在）。

**能耗公式**：
ΔE = Σ Δtᵢ·Iᵢ·pᵢ（n 个能耗状态；pᵢ 为状态 i 的功率；Iᵢ 为指示变量，Δtᵢ>0 取 1）。占空比高比工作功率，占空比低比睡眠功率。

**P = CV²FT**：
能耗与主频的关系式（课件"关键特性 3"）。

**Grove port**：
连接套接口，外设接入容易、快速且不易出错；对比引脚+杜邦线（复杂易错，可能烧坏外设和主板）。

**盾板（Shield）**：
与主板同外形、插上后覆盖主板的扩展板，扩展功能与接口；如 Arduino 的 Base Shield、树莓派的 GrovePi+ / Grove Base HAT。插上后无法再用杜邦线接引脚外设。

**UART**：
异步逐位传输数据的全双工通信接口标准（RX/TX 两引脚，无时钟同步，约定数据位长与波特率）。每次传输 11 位=8 数据+2 标识+1 校验。

**I2C**：
Phillips 公司推出的高性能串行总线；SDA+SCL 两线，半双工，先来先服务；地址高 7 位为从设备地址、最低位为读写方向（0 写 1 读）。

**SPI**：
高速、全双工、同步的通信总线；MISO/MOSI 两根数据线；BR=fBUS/BRD，BRD=(SPPR+1)×2^(SPR+1)。

**PWM**：
基于数字信号的脉冲调制技术，由频率与占空比组成；用于控制 LED/电机功率、降低能耗。

**可扩展性**：
开发板对接入外接设备种类和数量的支持程度；接口数量和接口类型是评估的重要指标。

**setup-loop**：
Arduino 代码结构：setup 为程序入口、仅执行一次（初始化）；loop 为循环体，setup 返回后重复执行。

**交叉编译**：
在 PC（Arduino IDE）上编译出目标开发板可执行代码的过程。

**TOPS / TFLOPS / GFLOPS**：
TOPS=每秒 10¹² 次操作（默认 INT8 整型）；TFLOPS=每秒 10¹² 次浮点运算（通常 FP32）；GFLOPS=每秒 10⁹ 次浮点运算。

**AVR / 哈佛结构**：
AVR 为挪威理工学者开发的 RISC 精简指令集体系结构（Arduino ATmega 系列所用）；哈佛结构指数据寻址空间与程序寻址空间分离。

## 第 3 章概念（操作系统）

**宏内核 / 微内核 / Library OS**：
宏内核=大量 OS 功能集成在一个内核态大进程（如 Linux）；微内核=只保留任务/线程管理、内存管理、IPC，其余服务作用户态进程经消息传递通信；Library OS=把 OS 功能当库直接链接进应用，减少上下文切换。

**Bootloader**：
设备加电后执行的第一段代码：初始化硬件 → 装载 OS/应用 → 跳转启动。

**差分文件**：
新旧版本代码做差分得到的升级补丁，由 COPY（5 字节）与 ADD（3+m 字节）指令构成；OTA=通过 Wi-Fi 等无线方式做软件更新。

**protothreads**：
Contiki 的协作式、单堆栈轻量线程框架（Adam Dunkels 2006），不能用局部变量保存状态；对比 mt_thread（多堆栈多线程库，支持协作式与抢占式）。

**RPL / CTP**：
RPL=面向低功耗有损网络的 IPv6 距离矢量路由协议，组织成 DODAG，支持多对一/一对多/一对一；CTP=基于 ETX 的收集树协议。

**ETX**：
期望传输次数（链路质量路由度量）=1/PRR；路径 ETX 为各跳相加。

**GNRC / SAUL**：
GNRC=RIOT 的通用网络协议栈（最底层 gnrc_netdev 抽象链路层）；SAUL=RIOT 的传感器/执行器抽象层（saul_reg_t / saul_driver_t / phydat_t 统一读写接口）。

**TinyML**：
把机器学习模型部署到微控制器与低功耗边缘设备的 ML 分支；三大压缩技术=量化、剪枝、蒸馏。

**分布式软总线**：
HarmonyOS 在 1+8+N 设备间搭建的"无形"总线：自发现、自组网、高带宽、低时延。

**Intermittent Computing**：
能量采集节点断电前把状态存入非易失内存、来电后恢复运行的计算模式（代表系统 InK）。

## 第 4 章概念（边缘智能）

**模型规模（参数量）/ FLOPs / FLOPS**：
参数量=模型有多少可学习权重；FLOPs/MACs=跑一次前向需要的计算量；FLOPS=硬件每秒能做的浮点运算（峰值算力）。规模和计算量决定模型能不能放到端上。

**量化（Quantization）**：
把高精度浮点权重/激活映射到低精度整数：Q = round(x/Scale) + ZeroPoint；分线性/非线性、对称/非对称、动态/静态/量化感知训练（QAT）。RTN 失效时可用 LLM.int8() 类方法。

**剪枝（Pruning）**：
删掉冗余权重/通道：非结构化（按 L1 范数等判据删单个权重，压缩率高但需稀疏硬件）vs 结构化（删整条通道/滤波器，硬件友好）。理论依据含"彩票假设"。

**知识蒸馏（KD）**：
Hinton 2015：大模型（teacher）教小模型（student），用组合损失 L=α·CE(硬标签)+(1−α)·T²·KL(软标签)，温度 T 控制软标签平滑度。

**云边协同**：
智能路由（按负载/位置选执行位置）与分割计算（把模型切开放边缘+云，如 pool5 最佳切分点）；两条规律：数据量决定传输开销、延迟决定体验。

## 第 5 章概念（无线通信协议）

**LPWAN**：
低功耗广域网：远距离、低速率、低功耗，代表 SIGFOX/LoRa/NB-IoT/LTE-M/EC-GSM/LTE Cat 1。

**DSSS / O-QPSK**：
802.15.4 物理层：直接序列扩频（4bit→32 码片）+ 偏移四相相移键控（I/Q 支路错开半个码元 0.5μs）。

**CCA / LPL / RI-MAC**：
CCA=空闲信道评估（发送前侦听）；LPL=低功耗侦听（周期唤醒+长前导）；RI-MAC=接收方发起的 MAC（接收方发 beacon 约定唤醒）。

**RSSI / SNR / LQI / PRR**：
四个链路质量指标：接收信号强度、信噪比、链路质量指示、收包率；EWMA 用于平滑估计。

**piconet**：
蓝牙微微网：1 主 + 最多 7 活动从设备。

**GATT / ATT**：
BLE 属性协议与通用属性规范，服务/特征值组织数据的框架。

**PSM / eDRX**：
NB-IoT 的两种省电模式：PSM 深度睡眠不监听寻呼；eDRX 拉长寻呼周期。

**CSS（chirp 扩频）/ Class A/B/C**：
LoRa 用线性调频扩频；LoRaWAN 三种设备类：A（上下行后开窗，最省电）、B（定时开窗）、C（持续接收，最费电）。

**6LoWPAN**：
IPv6 适配层：数据包分割重组 + IPv6/UDP 包头压缩，让低功耗网络跑 IPv6。

## 第 6 章概念（云平台）

**CMP / DMP / AEP / BAP**：
四类物联网云平台：连接管理、设备管理、应用使能、业务分析；四类并非互斥，一个平台可提供多类服务。

**发布订阅 / Broker**：
MQTT 通信模型：发布者与订阅者解耦，经 Broker 按主题转发；主题通配符 `+`（单层）/`#`（多层）。

**QoS 0/1/2**：
MQTT 三级服务质量：至多一次、至少一次（可能重复）、恰好一次；在途窗口上限 C 与往返 RTT 决定吞吐上界 C/RTT。

**设备影子（desired/reported）**：
云端保存的设备状态副本：desired=期望状态（App 写）、reported=上报状态（设备写），弱网也能读写。

**IFTTT**：
If This Then That 规则引擎：条件触发动作；冲突检测可用 SAT/SMT（Z3 求解器）判定规则是否矛盾。

**时序数据库 / Gorilla 压缩**：
面向时间序列优化的存储（tag/field 模型）；Gorilla 用 XOR 编码压缩时间戳与数值。

**滑动窗口 / 增量算法**：
流计算按窗口聚合；增量算法用"减去出窗+加上入窗"把复杂度从 O(n·w) 降为 O(n)。

**HMAC / IBC / KGC**：
消息认证码（共享密钥+哈希）；标识基密码体制（公钥即标识，由 KGC 密钥生成中心发私钥）。

**计算卸载 / outbox 补传**：
卸载临界条件：若边缘耗时 E ≤ 往返 L+云端处理 C，云端不可能更快；断网时本地 outbox 缓存、恢复后补传，净清理速率=上传能力−新增速率。

## 第 7 章概念（云-端一体开发）

**云-端一体开发平台**：
涵盖物联网应用整个开发流程（设备端+云端+应用端）的平台，解决应用开发碎片化、标准不统一、技术栈复杂三大问题。

**MicroPython / Node-RED**：
端侧解释型语言开发（无需编译，装解释器即可）与可视化流程编排工具。

**物模型（TSL）**：
数字孪生模型：属性（状态）、事件（上报）、服务（可被调用）三件套；IoT Studio 用 JSON 描述。

**RRPC**：
云平台提供的同步 RPC 通道：云端请求 → 设备响应，区别于普通异步 Topic。

**NDN（兴趣包/数据包）**：
命名数据网络：按名字请求数据（Interest），路由器可缓存（Data）；对比 TCP/IP 按地址通信。

**TinyLink 自顶向下开发**：
先写应用代码与需求，云端自动生成硬件方案+系统软件（210 条约束、lp_solver 求解、225 个 API/24 类）；2.0 支持更多硬件与联动。

**服务编排 / 服务节点**：
IoT Studio 里把云服务像流程图一样串起来（九大类节点），低代码实现业务逻辑。

**面板（Panel）**：
Tuya 给标准设备自动生成的 App 控制界面；零代码（自动固件）/低代码（MCU SDK）/多代码（设备 SDK）三档。

## 第 8 章概念（物联网安全）

**被动/主动攻击**：
被动=嗅探、扫描、窃听（不改变信息、难察觉）；主动=假冒、篡改、重放、DoS、干扰、病毒（更改信息，威胁完整性与可用性）。

**PUF / RoT**：
物理不可克隆函数（用制造差异生成唯一密钥）；信任根（硬件级可信起点）。

**Secure Boot / TEE（CA/TA）**：
安全启动=逐级验证固件签名才放行；可信执行环境=隔离运行安全应用（TA），普通侧为 CA。

**侧信道攻击（SCA/SPA）**：
不攻算法本身，从功耗/电磁/时间等物理泄漏反推密钥；SPA 适用于密钥相关跳转、功耗差异大的算法（RSA/ECC）。

**蜜罐（Potd）**：
伪装成真实服务诱捕攻击者、收集攻击样本的防御手段。

**设备三元组**：
阿里云设备身份三要素：ProductKey + DeviceName + DeviceSecret。

**NwkSKey / AppSKey**：
LoRaWAN 双会话密钥：网络会话密钥（校验完整性）与应用会话密钥（端到端加密载荷）。

**TLS 记录/握手协议**：
TLS 两层：握手协议协商密钥与认证，记录协议加密传输数据。

**海豚音攻击（DolphinAttack）**：
用超声波（人耳听不到）携带语音指令攻击语音助手。

**假名与假位置**：
隐私保护：用临时身份（假名）替代真实身份、上报扰动位置（假位置），兼顾可用服务与隐私。
