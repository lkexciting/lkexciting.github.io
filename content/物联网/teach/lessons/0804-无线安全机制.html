无线安全机制

一句话：蓝牙、ZigBee、RFID、LoRaWAN、NB-IoT 五大无线技术的安全设计——协议名 + 防什么攻击，一一对应必须记牢。

本课依据

考试内容以 PPT（课件）为准。本课对应课件《第八章-v2(2)》第 2 节"安全机制3：无线安全机制"【教材 PPT 补充单独标注】。原始课件：第八章-v2(2).pdf

一、蓝牙与 ZigBee 安全

蓝牙安全（配对流程）

蓝牙内置 4 种安全模式，以安全模式 1 到 4 命名，数字越大安全级别越高。配对五步：① 手机程序向设备发送配对请求；② 设备与手机直接交换配对信息；③ 双方进行认证与加密（分两步：先交换公钥并生成对称密钥，再按配对方案认证彼此）；④ 认证通过后根据对称密钥生成长期密钥；⑤ 建立加密通道，之后所有信息由长期密钥加密后发送。

ZigBee 安全（每层都有设计）

刷新计数器：设备有输入/输出刷新计数器，新密钥建立时计数器重置——以此阻止重放攻击；数据包完整性检查：基于循环冗余校验（CRC），防止攻击者修改数据；认证功能：防止模仿合法设备，可应用在网络层（公共的网络密钥）和设备层（两设备间唯一的链接密钥）；加密功能：128 位 AES 加密算法阻止窃听者侦听，使用 3 种基本密钥：主密钥、链接密钥、网络密钥。

二、RFID 安全协议（流程 + 缺陷，必考）

协议机制缺陷（课件原文）
Hash-Lock 协议使用经哈希函数处理的 metaID 代替真实 ID，防止信息泄露。流程：收到查询请求 → 标签返回加密的 metaID → 读写器用 metaID 查数据库获得真实 ID 与加密 ID 的 key → key 发给标签 → 标签验证 key 后发真实 ID → 读写器对比认证没有 ID 与 metaID 的刷新机制；ID 与 key 以明文通过不安全信道传送——非常容易遭受重放与假冒攻击，攻击者也很容易追踪标签
随机化 Hash-Lock 协议基于 Hash-Lock，采用基于随机数的询问-应答机制。流程：标签生成随机数 R，将 h(R||ID) 与 R 一同发送 → 读写器查询所有 ID，分别与 R 哈希后与收到的 h(R||ID) 比对找到正确 ID → ID 发给标签验证后访问抵御了重放与假冒攻击，但标签 ID 仍以明文通过不安全信道传送，攻击者依旧可追踪标签
教材 PPT 补充

RFID 除信号传输隐患（窃听、中间人攻击、欺骗、重放、拒绝服务等）外，还面临针对设备的攻击（物理破坏、信息篡改、电子破坏、屏蔽干扰、拆除）与隐私问题——不安全标签可能在用户无察觉时被附近读写器读取，暴露位置隐私、使用户被跟踪。其他 RFID 协议还有基于散列函数的 ID 变化协议、Hash 链协议、数字图书馆 RFID 协议、LCAP 协议和基于公钥密码机制的 RFID 安全方案（具体细节课件未展开）。

三、LoRaWAN 与 NB-IoT 安全

LoRaWANNB-IoT
认证与密钥每个终端有唯一的 128 位 AES 密钥 AppKey 和唯一设备标识符 EUI-64-based DevEUI，两者都用于设备认证；终端根据 AppKey 生成两个会话密钥：NwkSKey（network session key，确保设备与网络服务器间数据包的完整性）和 AppSKey（application session key，应用层加密解密，保护设备到应用服务器间的数据隐私）；两者共同建立终端-网络层、终端-应用层的双向认证无线信号安全：使用授权频段，保证传输效率、减少被攻击可能；终端安全：认证凭证采用 SIM 卡存储，经长时间大范围安全考验，全球认可；认证机制：基于标准 3GPP 的身份认证与密钥协商协议和数据传输层安全协议进行网络层/传输层认证；密钥管理：采用标准的基于哈希化信息验证码的提取/扩展密钥派生函数算法（HKDF），网络层和传输层密钥由不同机制生成且彼此独立、两层安全互不影响
完整性保护每帧数据包设置：帧计数器（防止数据包重传）、信息完整性验证码 MIC（message integrity code）、基于 AES 加密的信息真实性验证码 CMAC（cipher-based message authentication code）——
教材 PPT 补充：无线系统安全技术分类

① WEP 加密：IEEE 802.11b/a/g 中的可选安全组件（无线等效协议），对访问者身份识别并加密传输内容；② MAC 地址过滤：无线路由器只允许特定 MAC 地址通信或禁止黑名单 MAC 访问；③ 禁用 SSID 广播：SSID 广播暴露无线路由器位置，大部分路由器已禁用自动广播。典型无线系统：蓝牙、Zigbee、RFID、LoRa、NB-IoT 等。

课件思考题（本课相关）

1. ZigBee 设备在数据加密过程中使用哪三种基本密钥？认证功能分为哪两层？

点开看参考答案

三种基本密钥：主密钥、链接密钥、网络密钥。认证功能防止攻击者模仿合法设备，可应用在网络层（通过使用一个公共的网络密钥）和设备层（在两个设备之间使用唯一的链接密钥）。（课件"安全机制3：无线安全机制——ZigBee安全"原文；课件未给出更进一步的展开）

2. Hash-Lock 协议与随机化 Hash-Lock 协议各自解决了什么问题、还遗留什么问题？

点开看参考答案

Hash-Lock 协议用 metaID 代替真实 ID 防止信息泄露，但没有 ID 与 metaID 的刷新机制，ID 与 key 以明文通过不安全信道传送，容易遭受重放与假冒攻击，攻击者也可很容易地追踪标签。随机化 Hash-Lock 协议在其基础上采用基于随机数的询问-应答机制，可抵御重放与假冒攻击，但标签 ID 仍以明文形式在不安全信道传送，攻击者依旧可以对标签进行追踪。（课件"RFID安全"两页原文归纳）
