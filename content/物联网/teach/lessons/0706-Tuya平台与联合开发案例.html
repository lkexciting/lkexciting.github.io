一、Tuya IoT 开发平台

简介：涂鸦智能于 2016 年推出的全球化 IoT 开发平台，向开发者提供硬件开发、云服务开发和 App 开发等工具；平台开发设备可接入 Amazon Alexa、Google Assistant、Apple HomeKit、SmartThings 等生态。截至 2021 年 7 月，累计有超过 37.4 万注册开发者，产品和服务覆盖超过 200 个国家和地区。

维度要点（课件原文）
设备端开发（三档）零代码——针对电工、照明、传感等功能相对标准的设备，如平台预定义插座功能，开发者可视化 UI 配置功能并选择无线通信模组，平台自动为模组生成固件；低代码——针对硬件方案中有 MCU 的产品，平台提供 MCU SDK，开发者调用相关接口完成应用；多代码——针对网关、摄像头等其它复杂硬件设备，平台提供对应的设备 SDK
云服务开发流程创建并配置云项目 → 添加设备 → 代码开发。代码要点（Python）：初始化 TuyaOpenAPI(ENDPOINT, ACCESS_ID, ACCESS_KEY) 并 login；构造开关命令 commands = {'commands':[{'code':'switch_led','value':flag}]}；经 openapi.post('/v1.0/devices/{}/commands'.format(DEVICE_ID), commands) 由云服务下发
移动端开发控制智能产品的界面程序——面板（Panel）：基于 React Native 框架实现，保留原生移动应用的流畅体验；可在工作台拖拽组件完成设计，也可基于 SDK 设计新面板。面板嵌入移动应用三种方式：公版 App、零代码开发 OEM App、使用 SDK 进行本地 App 开发
平台特性（四条）成熟的硬件解决方案（电工、照明和家电等）；灵活的边缘计算网关（Docker 镜像方式安装，跨平台，部署方便，支持多种主流物联网标准协议接入，也支持用工具集快速开发私有协议驱动）；便捷的 SaaS 开发框架（面向 IoT SaaS 开发者的前后端开源框架，集成用户登录、角色权限等基本功能）；全球公有云（整合不同主流公有云的全球服务节点）

二、IoT Studio 开发案例：智能教室座位使用统计

案例描述：设备部署在教室，自动监测座位上是否有人，并在 Web 页面实时显示。需要的设备：树莓派 4B + 红外热释电运动传感器。九个步骤：

  1. 进入 IoT Studio 工作台（https://studio.iot.aliyun.com/），创建空白项目并在项目下创建产品。
  2. 为产品自定义功能：添加两个属性——设备编号（deviceID）和红外检测状态（motionState）。
  3. 硬件连接：树莓派引脚 5V / GND / GPIO18 分别接传感器 VCC / GND / D1。
  4. SDK 安装：项目目录下安装 aliyun-iot-device-sdk（云平台接入 SDK）与 Pigpio（树莓派 GPIO 相关接口）。
  5. 设备端代码编写（JavaScript）：aliyunIot.device({productKey, deviceName, deviceSecret}) 创建设备实例；gpio_pir.digitalRead() 读传感器；device.postProps({deviceID, motionState}) 上传；setInterval(postProps, 10000) 周期上传。
  6. 进入 IoT Studio 项目，新建基于可视化搭建的 Web 应用。
  7. 使用指示灯、文本框、文字时钟等组件搭建 Web 页面。
  8. 配置指示灯组件的数据源。
  9. 在 Web 应用开发控制台点击页面预览，查看效果。

IoT Studio 设备端开发的不足（两条）：①支持的硬件种类较少（以 JavaScript 开发为例：ESP32-乐鑫、STM32F/L4XX 与 STM32F7XX-意法半导体、EMW3060/EMW3080-庆科、STM32F103X-意法半导体，操作系统为 AliOS-Things / FreeRTOS / UCOSII 的组合）；②仍采用传统的自底向上的开发方式。

三、IoT Studio + TinyLink 联合开发（压轴计算题）

分工：使用 TinyLink 实现设备端开发，云端服务开发和 Web 应用/移动应用开发由 IoT Studio 完成。关键点：使用 TinyLink 实现基于物模型的设备接入。设备使用 MQTT 协议连接阿里云，连接参数：

参数名称参数值
serverName${productKey}.iot-as-mqtt.cn-shanghai.aliyuncs.com
port1883
clientNameclientId+"|securemode=x,signmethod=xxxxxx,timestamp=xxxxxx|"——clientId 用户自定义（64 字符以内）；timestamp 当前时间；signmethod 签名算法（支持 hmacSha1、hmacSha256、hmacMd5）；securemode 安全模式（2＝TLS 直连，3＝TCP 直连）
userNamedeviceName + "&" + productKey
passWordsign_hmac(deviceSecret, content)，content =（productKey, deviceName, timestamp, clientId）

示例：设备属性 clientId=12345、deviceName=device、productKey=pk、timestamp=789、signmethod=hmacsha1、deviceSecret=secret → serverName pk.iot-as-mqtt.cn-shanghai.aliyuncs.com；clientName 12345|securemode=3,signmethod=hmacsha1,timestamp=789|；userName device&pk；passWord hmacsha1("secret","clientId12345deviceNamedeviceproductKeypktimestamp789").toHexString() = FAFD82A3D602B37FB0FA8B7892F24A477F851A14。

# TinyLink 设备开发示例（智能教室座位统计接入 IoT Studio）要点 TL_MQTT mqtt; mqtt = TL_WiFi.fetchMQTT(); // 连接 WiFi 后获取 MQTT int mqtt_conn = mqtt.connect(serverName, port, clientName, userName, password); // loop 中：TL_PIR.read() 读传感器 → 按物模型构造 payload（id/version/params/ // {deviceID, motionState}/method="thing.event.property.post"） mqtt.publish(propertyPostTopic, buf, payloadlength); // 发到 /sys/pk/device/thing/event/property/post messageID++; TL_Serial.println(buf); mqtt.yield(4000);

四、总结：三平台比较（必背大表）

平台名称设备开发服务开发Web/移动应用开发特点
TinyLink采用硬件无关的 TinyLink 语言，支持云端编译支持基于 IFTTT 规则的服务开发基于设备端代码自动生成应用框架，开发难度最低开发简单，适合物联网技术的初学者
Link Develop（IoT Studio）提供基于 SDK、基于 AliOS-Things、基于解释型语言多种设备端开发方式提供基于可视化服务编排的服务开发方式提供可视化搭建的应用开发方式，适合初学者支持多种开发方式，开发更为灵活
Tuya IoT 平台提供零代码开发方式和基于 SDK 的低代码/多代码开发支持基于脚本语言的规则开发提供可视化搭建的应用开发方式，也提供基于 SDK 的开发方式开发简单，解决方案成熟，对工业界支持较多

习题 6：某设备参数为 clientId=1001、deviceName=bulb、productKey=bulbkey、securemode=3、timestamp=123、signmethod=hmacsha1、deviceSecret=mysecret。计算使用 TinyLink 连接 Link Develop 平台的 MQTT 连接参数。

点开看参考答案

serverName：bulb.iot-as-mqtt.cn-shanghai.aliyuncs.com（productKey 拼前缀）；port：1883；clientName：1001|securemode=3,signmethod=hmacsha1,timestamp=123|；userName：bulb&bulbkey；passWord：8ea1b574a7f1e6b51a1afb73149c8e5906635e93（＝hmacsha1 对 content="clientId1001deviceNamebulbproductKeybulbkeytimestamp123" 以 mysecret 为密钥计算）。（出处：教材课后习题答案第 6 题）
