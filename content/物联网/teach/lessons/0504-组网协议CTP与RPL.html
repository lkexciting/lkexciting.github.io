组网协议：6LoWPAN、CTP 与 RPL

一句话：从"让 IPv6 跑在 802.15.4 上"到"多跳路由怎么选路"，CTP 的 ETX 和 RPL 的 DODAG 是本章路由大题的核心。

本课依据

考试内容以 PPT（课件）为准。本课对应课件"基于 IEEE802.15.4 的传感网协议"一节中的"6LoWPAN、CTP&RPL、THREAD、Matter"部分【教材 PPT 补充单独标注】。原始课件：第五章 低功耗无线协议2026.pdf

一、6LoWPAN：IPv6 跑在 802.15.4 上

6LoWPAN = IPv6 over Low Power Wireless Personal Area Network，致力于将 IPv6 与 802.15.4 相结合，使大量物联网节点无缝接入互联网。主要任务：在 802.15.4 MAC 层与 IPv6 网络层之间加入适配层。两种主要技术：分段重组、头部压缩。

技术课件要点
分段重组MAC 每帧 127 字节，802.15.4 能提供的有效负载仅 80~100 字节；而 IPv6 数据报 MTU 为 1280 字节 → 必须分段重组。分段字段：Size（每个分段大小，所有分段都含）、Tag（同一 IPv6 报文的分段 Tag 相同）、Offset（在原报文中的位置；第一个分段省略，其它分段必须包含）。
头部压缩IPv6 头部 40B、UDP 头部 8B。最关键的是压缩源/目的 IPv6 地址（共 32B）：基本思想是利用链路层地址与 IPv6 地址之间的直接映射关系（64 位前缀 + 64 位 IID，IID 由链路层地址直接配置而成；本地链路单播地址 FE80:: 开头）。其它字段：限定常用值个数并编号，或直接省略能从 MAC 层头部获取的字段——版本 Version 与有效载荷长度 PayloadLen 可直接省略。

二、CTP：多对一汇集树协议

CTP：多对一的路由模式；基于距离向量路由协议，选择距离最短的路径；建立在 CSMA MAC 或 LPL MAC 及链路质量估计器之上。

2.1 路由指标 ETX（必考计算）

链路 ETX：在一条链路上成功发送一个数据包所需的传输次数 ETX = 1 / (df × dr) ≈ 1/df df：数据包成功到达接收者的概率 dr：接收者回复的 ACK 包成功到达发送者的概率 路径 ETX：在一条路径上成功发送一个数据包所需的传输次数

2.2 基本工作流程（beacon 逐跳收敛）

① 根/S 节点广播 beacon，邻居 A、B 更新路由表（下一跳、开销）；② A 再广播 beacon，B 发现走 A 路径更优，更新父节点为 A；其余邻居 C、D 分别更新路由；③ 重复此过程直到全网收敛。每个节点维护"下一跳 + 开销（path ETX）"。

2.3 帧格式

帧字段
路由帧（beacon）P：路由信息请求标志位，置位则收到该包的节点将发送路由帧更新路由信息；C：拥塞标志位，置位表示上一个 CTP 包丢失、发生拥塞；Parent：beacon 发送节点的父节点；ETX：发送节点的 path ETX
数据帧P、C 同上；THL（Time Has Lived）：数据包生成时为 0，每经过一跳加 1；ETX；Origin：源节点 ID；SeqNo：序列号

2.4 路由回路问题与 Beacon 频率

  • 回路发生原因：路由信息陈旧、没有及时更新。如何发现：数据包中的节点 ETX 应逐跳减小；当节点收到的数据包 ETX 比自己的 ETX 低时，说明发生回路。两种解决机制：通过广播 beacon 包解决不一致性；当数据包 ETX 高于设定阈值时不再发送该数据包。
  • Beacon 频率两难：过高 → 路由信息准确但开销大；过低 → 无法及时更新路由。解决：自适应调节（Adaptive beaconing），beacon 间隔从小到大增加；检测到网络不一致性（如路由回路）时将 beacon 间隔设成最小。

三、RPL：低功耗有损网络的 IPv6 路由协议

RPL = IPv6 Routing Protocol for Low Power and Lossy Networks（Ripple）。前提：IPv6 与 802.15.4 的结合是 6LoWPAN，基于 6LoWPAN 的路由策略是 RPL。

  • 组网模式：DODAG（Destination-Oriented DAG）——只有一个根节点的有向无环图。
  • 通信模式：MP2P（数据收集）、P2MP（数据分发）、P2P（点对点，由前两种模式结合实现，即上行+下行）。
  • 目标函数：选取路由度量（跳数、延迟、ETX 等）计算 Rank 值，考虑路由约束条件，选出最优路径——Rank 值最低的路径。
  • 上行路由建立：根节点向下广播 DIO 消息（含节点 ID、Rank 值等），收到者依据目标函数选择是否加入或更换父节点。
  • 下行路由建立：在建立好的上行路由上，节点向父节点发送 DAO 消息（含路由前缀信息）。
  • 课件建立过程示例（路由度量 ETX）：LBR-1 广播 DIO → A、B、C 设 LBR-1 为父节点加入 DAG → C 广播 DIO，B 添加 C 为可选父节点、E 加入 DAG（距离 3）→ A 广播 DIO，B 发现 A 是更优父节点而改路由到 A → 持续到所有节点加入 DAG。

四、THREAD 与 Matter（了解级）

协议课件要点
THREAD针对 IEEE 802.15.4 设备设计的 IPv6 网络协议栈（基于开放标准，可安全连接数百设备并直连云）；节点两种角色：路由节点（router）与端节点（end device）。设备类型：FTD（Full Thread Device：Router、REED——Router Eligible End Device、FED——Full End Device）与 MTD（Minimal Thread Device：MED——Minimal End Device、SED——Sleepy End Device）。
Matter一个统一的、基于 IP 的应用层连接协议；前身 Connected Home over IP（CHIP），由亚马逊、苹果、谷歌和 Zigbee 联盟共同发起；工作在 OSI 七层模型的传输层以上，依赖 IPv6。与传感网的关系：与 BLE、Thread、Wi-Fi、以太网等支持 IP 的无线技术配合实现互联互通，把分散的传感网协议整合成商用融合架构。组网模式：单一网络拓扑（所有 CHIP 设备连到单一逻辑网络：Thread/802.15.4、Wi-Fi 或以太网；Node 是 fabric 中 CHIP 设备的单个实例）与星形网络拓扑（多个外围网络经中央集线器网络相连，外围网络必须通过一个或多个边界路由器 Border Router 直连集线器网络）。

课件思考题（本课）

证明题：已知一条 n 跳路径 P=(e1,…,en)，其中 ei 代表第 i 跳的链路。证明这条路径的 ETX 等于其所有链路 ETX 之和。

点开看答案

一条路径的 ETX 表示在这条路径上成功传输一个数据包所需要的传输次数。一个数据包在一条路径上传输成功，需要在每一跳的链路上都传输成功：在第一跳链路 e1 上需要传输 ETX(e1) 次，然后继续在第二跳链路上传输 ETX(e2) 次……直到第 n 跳链路需要传输 ETX(en) 次。因此路径 P 上总共需要传输的次数为 Σ(i=1→n) ETX(ei)，即路径 ETX 为组成该路径的所有链路 ETX 之和。（课后习题答案第四章第 6 题）

计算题：路径收包率 = 源节点成功发送的数据包数占发送总数的百分比。两跳链路构成的路径，前一跳 ETX=1、后一跳 ETX=100，路径收包率多少？反过来呢？

点开看答案

ETX=1 表示该链路数据包只需传输一次，链路 PRR=1；ETX=100 表示发送 100 次失败 99 次，链路 PRR=0.01。路径 PRR = 各跳 PRR 之积：两种顺序均为 1×0.01 = 0.01（即 1%）——串联路径由最差链路主导，与顺序无关。（课后习题答案第四章第 7 题）
