云-端一体开发概述与设备端开发

一句话：物联网技术栈太复杂，所以要"云-端一体"；这节讲平台的定义、四大功能总览，以及设备端开发的三种方式（本地编译 / 云端编译 / 解释型语言），是全章表格题的地基。

本课依据

考试内容以 PPT（课件）为准。本课对应课件《第七章》第 1–2 节【概述 + 主要功能·设备端开发】（教材 PPT 补充单独标注）。原始课件：D:\学习文件\大三上\物联网技术基础与应用开发\第七章.pdf

一、为什么需要云-端一体开发平台（必背）

课件原话：物联网技术栈复杂，一个完整的物联网应用涉及嵌入式开发、网络协议、云平台开发、Web 开发、移动开发等多个领域。三个课件实例：

  • 空气质量监测应用：传感器网络层（嵌入式开发）+ 数据传输（WiFi、蓝牙、GRPS）+ 云服务层（云服务开发）+ 应用层（Web 应用、APP、小程序）。
  • 共享单车：数据传输蓝牙、NB-IoT、GRPS……；服务端如微软 Azure（摩拜）；移动应用 APP、小程序。
  • 智能楼宇：多种异构嵌入式设备（SDS018、DHT11……）+ 复杂数据展示页面（折线图、文本框、仪表盘）。
定义（背）

为解决上述问题，各大厂商推出云-端一体开发平台，如三星 SmartThings、阿里云 IoT Studio、涂鸦智能 Tuya IoT 等，旨在涵盖物联网应用的整个开发流程，解决物联网开发领域存在的应用开发碎片化、标准不统一、技术栈复杂等问题。

理想的物联网云-端一体开发应包括四大功能（全章目录，必背）：①支持设备端开发 ②支持云服务开发 ③支持 Web 应用/移动应用开发 ④支持三端集成开发流程的简化。

二、设备端开发：三种方式（核心表格）

现状与问题：物联网设备种类繁多，不同种类的设备需要不同的开发语言（C/C++、Python、JavaScript……）和开发环境（IDE：Keil、IAR、ARDUINO……）。为此设备端开发分三种方式：

方式要点（课件原文）
基于本地编译基于设备模型，通过 SDK 等方式提供统一的设备操作与平台接入接口；需要开发者在本地配置开发环境。两条路线：基于 SDK（SDK 是开发所需资源的集合，包括 API 函数、帮助文档、开发工具等，为开发者屏蔽底层硬件细节）；基于物联网操作系统（提供统一开发接口，及任务调度、资源管理、软件更新等功能）
基于云端编译代码可在本地或云端编写，编译过程放在云端；无需在本地搭建编译环境；编译资源可动态分配，编译速度快、编译成本低
基于解释型语言使用 JavaScript、MicroPython 等解释型语言无需编译；设备端需要安装解释器。与编译型语言不同：跨平台容易、代码可移植性强。例：IoT Studio 在线 JavaScript 开发工作台

三、解释型语言的两个代表：MicroPython 与 Node-RED

MicroPython：一种适用于微控制器的 Python 3 编程语言实现。特点：平台支持（STM32、ESP32、RA4M1、nRF51 等成熟开发框架）；驱动支持（可与 GPIO、SPI、I2C、ADC、DAC、PWM 等多种设备通信）；高效小巧（脚本语言高效、代码大小小巧）。支持的硬件平台：ESP8266、ESP32、STM32、pyboard、WiPy 等。

MicroPython 特定的库：machine（与硬件相关，直接访问 CPU、定时器、总线等硬件块）、network（网络配置，提供特定硬件的网络驱动）、bluetooth（低级蓝牙，支持 BLE 中央/外设/广播/观察者角色及 GATT 服务器客户端）、micropython（访问控制内部结构）、cryptolib（密码）、framebuf（帧缓冲区）、uctypes（结构化访问二进制数据）。

# machine 库用例：控制 LED 灯 from machine import Pin import time led = Pin(2, Pin.OUT) # 初始化 LED while True: led.value(not led.value()) # 闪烁 time.sleep(1) # machine 库用例：使用中断 def handle_interrupt(pin): print('Interrupt detected!') interrupt_pin = Pin(4, Pin.IN) interrupt_pin.irq(trigger=Pin.IRQ_FALLING, handler=handle_interrupt)
# network 库用例：连接 Wi-Fi import network, socket station = network.WLAN(network.STA_IF) station.active(True) station.connect(ssid, password)

Node-RED：使用可视化编程方法，允许开发人员将预定义的代码块连接起来执行任务；基于流的编程模型，表示节点间事件流的消息、触发及输出结果的处理。基于 Node.js 构建，充分利用其事件驱动的非阻塞模型，适合在 Raspberry Pi 等低成本硬件以及云中的网络边缘运行。课件案例：用 Node-RED + Raspberry Pi 控制 LED——Twitter 节点检测含 #LED 标签的推文生成消息 → Trigger 节点接收消息触发动作 → GPIO 节点控制树莓派 GPIO 引脚，LED 按设定模式闪烁。
