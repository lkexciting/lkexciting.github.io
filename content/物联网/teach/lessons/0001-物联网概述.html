二、物联网的定义（课件原文，背）

定义

物联网就是物理设备以及其他嵌入了电子器件、软件、传感器的物件组成的网络。这些物件具有感知能力、计算能力以及连接能力，从而能更直接地将物理世界集成到数字世界中。

定义的核心是物件的三种能力：感知（采集物理世界）、计算（本地处理）、连接（联网通信）。课件举的例子是智慧家居、共享单车。

三、起源与发展脉络

  • 1995：比尔·盖茨《未来之路》提出物物互联的基本思想。
  • 2005：国际电信联盟（ITU）指出，无所不在的"物联网"通信时代即将来临。
  • 2009：IBM 提出"智慧地球"；同年中国提出"感知中国"。
  • 近年：人工智能赋能物联网（AIoT），迈向"万物智联"。

课件还引了 ITU 描绘的图景：衣服会告诉洗衣机对颜色和水温的要求，公文包会提醒主人忘带东西——用来理解"物物互联"的直观含义。

四、发展趋势：三个阶段与连接数

物联网 1.0（2010–2015）

传感网、RFID

物联网 2.0（2015–2020）

操作系统、物联网云平台

物联网 3.0（2020 至今）

AIoT（AI + IoT）

数据（IoT Analytics）：2020 年物联网连接数达 117 亿，首次超过非物联网连接数；预计 2025 年增长到 309 亿，几乎是非物联网连接数的 3 倍。

各部分职责（课件原意）：

  • 终端感知设备：物联网末端的感知节点，负责采集数据。
  • 网关：设备通常以无线方式接入；网关无线接收数据，再通过有线把数据传输到云平台。
  • 云平台：存储感知数据；提供数据查询、分析、处理、展示；管理终端与网关的接入；提供多重安全防护。
  • 客户端：开发者面向用户开发的各类应用。

课件列出的常见设备 / 平台 / 软件：传感器、开发板、网络设备、云服务；开源软件如 Contiki、RIOT、Zephyr、RT-Thread、HarmonyOS，OpenWrt、EdgeX、KubeEdge，以及 ThingsBoard、IoTSharp（集成 MQTT、InfluxDB、Grafana 等组件）。

六、开发面临的三组"挑战 ↔ 机遇"

挑战对应的机遇
开发链长：一个应用涉及嵌入式、云平台、用户端开发，需嵌入式 / 前端 / 后端多类人员协作。 低代码开发：Gartner 预测到 2024 年 75% 的应用将在低代码平台开发；IEEE CS 将其列为 2022 年 16 大技术趋势之一。
没有固定的终端类型：物联网领域尚未形成统一的终端形态。 碎片化 / 异构性意味着没有独裁垄断；硬件可向低功耗、小体积等多元化方向发展。
垂直一体化架构：软硬件与云平台耦合，难以复用与标准化。 Matter 协议（用区块链做跨生态去中心化认证）与开源云平台 ThingsBoard / IoTSharp，使"标准化"开发成为可能。

七、四个典型应用（课件案例，记一句话）

无锡鸿山物联网小镇

全国首个以物联网为产业特色的小镇；"四个全国第一"；用阿里云飞凤平台（后演变为阿里云物联网平台）支撑智能楼宇、垃圾桶、井盖、消防等。

CMU GIoTTO 智慧校园

卡内基梅隆大学在 Google 资助下的 Living Lab；4 特点：终端用户可编程、支持广泛部署、支持机器学习、安全与隐私保护。

Mosaic 空气质量监测

低成本移动监测 PM2.5；PM2.5 指直径 <2.5µm 的粒子；云端用"多元线性模型 + 随机森林"两阶段校准。

港珠澳大桥结构健康监测

全长 55 公里，建设期已部署数千个传感器；面临数据异常/时间不对齐、有线传输部署难、定位数据质量不高等局限。

其中 CMU GIoTTO 的数据管理层值得记：中心服务器用 MongoDB（传感器/用户/建筑/访问控制列表），数据服务器用 InfluxDB 时序库，连接器负责设备通信；机器学习层把"打标签→训练分类器→虚拟传感器"串起来（案例：用虚拟分贝计 + 座位占用传感器找安静且有空座的教室）。安全上用 HTTPS、OAuth 2.0（ID+密钥换令牌）与访问控制层。

Mosaic 的粒子传感器原理也常考：风扇向上提供稳定气流 → 激光发射器发出红外激光 → 激光被气流中粒子反射 → 光传感器感知反射强弱，从而测出粒子浓度。

八、学术前沿与一个必会计算

课件列出的研究领域：RFID（有源阅读器 + 无源标签）、普适计算（任何时间地点计算、上下文感知）、无线传感器网络（集成计算/感知/通信的微型节点，多跳传输）。前沿方向：供电节能（电池→可再生能源→无源后向散射）、节点平台（MicaZ/TelosB→Arduino/树莓派）、通信组网（多跳 ZigBee→BLE/LoRa/NB-IoT）、智能感知（→边缘计算：降传输、降延迟、增隐私）。

必会：节点生命周期

公式 T = C / I（T 工作时长，C 电池容量，I 平均电流）。课件例：C=2800mAh，工作 20mA、休眠 0.5mA，占空比 10%：

平均电流 I = 20mA×10% + 0.5mA×(1−10%) = 2.45mA 工作时长 T = C / I = 2800mAh / 2.45mA ≈ 1142h

课件思考题 3 就是换占空比 1%、再叠加电池自放电 0.5%/天，自己算一遍。

八点五、概念详解：这道电池题到底在算什么（占空比 · 平均电流 · 自放电）

看不懂思考题 3，通常是三个概念没落地。用一个类比全讲通：电池 = 水箱。

① 容量 C 与电流 I

电池像水箱：容量 C（2800mAh）是箱里存了多少水；电流 I 是放水多快。mAh 的意思：以 1mA 放电能放 1 小时，所以 2800mAh = 按 1mA 放 2800 小时、按 20mA 只能放 140 小时。水用完的时间 T = C ÷ I。

② 占空比与平均电流

物联网节点大部分时间在睡觉（0.5mA），少数时间干活（20mA）。占空比 = 干活时间占比，1% 就是每 100 秒干 1 秒、睡 99 秒。电流忽大忽小没法直接除，按时间"加权平均"折成匀速：I = 20×1% + 0.5×99% = 0.695mA。谁的时间多就听谁的，所以平均值远小于 20。

③ 自放电 = 隐形漏电

电池不接设备也会自己漏电（内部化学反应）。课件口径：每天漏初始电量的 0.5%。解法是把"每天漏的电量"折成一个看不见的漏电流：2800×0.5% = 14mAh/天，14÷24 ≈ 0.583mA——相当于多接了一个一直耗 0.583mA 的隐形设备。

三步解题模板（考试直接套）
第 1 步：平均电流 I = 工作电流×占空比 + 休眠电流×(1−占空比) 第 2 步（若有自放电）：漏电流 = C × 自放电率 ÷ 24h，加进 I 第 3 步：T = C ÷ I（单位：小时），÷24 换成天

问①：I = 0.695mA → T = 2800÷0.695 ≈ 4029h（168 天）。问②：I = 0.695+0.583 = 1.278mA → T ≈ 2190h（91 天）。课件例题（占空比 10% → 2.45mA → 1142h）同一套方法，只是换数字。

九、课件思考题（先自己答，再点开对照 · 每题独立）

思考题 1

问 ①：一个典型物联网应用架构包括哪些部分？

点开看问 ① 的参考答案

六部分：终端感知设备 → 无线接入（BLE 5.0 / NB-IoT / Wi-Fi / GPRS）→ 网关 → 互联网 → 物联网云平台 → 客户端（Web / APP）。职责：终端感知设备采集数据；网关无线接收数据并经有线回传云平台；云平台存储感知数据、提供查询/分析/处理/展示、管理终端与网关接入、提供多重安全防护；客户端是面向用户开发的应用。（本课第五节即此图）

问 ②：物联网开发与传统 PC 程序开发有什么不同？

点开看问 ② 的参考答案

按课件"挑战"部分作答：① 开发链长——一个应用涉及嵌入式、云平台、用户端开发，需嵌入式/前端/后端多类人员协作；② 没有固定的终端类型——物联网领域尚未形成统一的终端形态；③ 垂直一体化架构——软硬件与云平台耦合，难以复用与标准化。

思考题 2

问 ①：在 CMU GIoTTO 项目中，如何保证安全性？机器学习层起到了什么作用？

点开看问 ① 的参考答案

安全三件套（课件原文）：HTTPS——在 HTTP 基础上加密通信；OAuth 2.0——用户用账户名、密码登录中心服务器后获得唯一 ID 和密钥，访问 GIoTTO 数据库时必须先用 ID 和密钥获取 OAuth 令牌才能获得数据访问权限，令牌有效期超时后必须重新生成；访问控制层——分管理员与普通用户，管理员拥有所有传感器数据访问权限并定义普通用户权限（访问控制列表）。机器学习层作用：给数据打标签 → 训练分类器 → 得到虚拟传感器——如训练虚拟分贝计、训练座椅加速度计数据得到座位占用虚拟传感器，两者结合即可检测安静环境下的空闲座位。

问 ②：在 Mosaic 项目中，PM2.5 测量的原理是什么？使用一元线性模型做数据校准有什么缺陷？

点开看问 ② 的参考答案

原理（课件原文）：风扇向上提供稳定气流 → 激光发射器发出一束红外激光 → 激光照射到气流上，被其中的粒子反射 → 被光传感器感知，通过反射的强弱程度测量粒子浓度。校准缺陷可对照课件给出的方案回答：课件实际采用多元线性模型 + 随机森林的二阶段校准——特征不只粒子原始数据，还有温湿度、速度、人流密度、车流密度等（Akaike 信息准则选特征防过拟合）；第一阶段多元最小二乘定线性模型参数，第二阶段用随机森林拟合线性模型的残差。可见单一特征的一元线性模型不足以刻画多因素影响，其残差中的非线性部分也无法拟合。

思考题 3

问 ①：电池 2800mAh，工作 20mA、休眠 0.5mA，占空比 1%，节点工作时长为？

点开看问 ① 的参考答案
I = 20mA×1% + 0.5mA×99% = 0.2 + 0.495 = 0.695mA T = C/I = 2800mAh / 0.695mA ≈ 4029h（约 168 天）

方法与课件例题（占空比 10% → 2.45mA → 1142h）完全一致，只换代入值。

问 ②：占空比 1%，且考虑电池自放电率 0.5%/天（课件假设：电池每天释放初始电量的 0.5%），工作时长为？

点开看问 ② 的参考答案
自放电等效电流 = 2800mAh × 0.5% ÷ 24h = 14mAh/24h ≈ 0.583mA 总等效电流 I = 0.695 + 0.583 = 1.278mA T = 2800mAh / 1.278mA ≈ 2190h（约 91 天）

说明：题目条件与假设均为课件原文，解法是把自放电按课件 T=C/I 的口径折算成等效电流；这是思考题，课件未给数值答案，建议以此思路与老师核对。
