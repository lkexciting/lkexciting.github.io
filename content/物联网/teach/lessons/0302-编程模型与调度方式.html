编程模型与调度方式

一句话：关键特性 1–2——程序怎么组织（模块化/事件/线程）、CPU 怎么分（四种调度），含必考的三线程调度计算题。

本课依据

考试内容以 PPT（课件）为准。本课对应课件《第三章-dw(3)》"关键特性 1：编程模型""关键特性 2：调度方式"节【教材 PPT 补充部分会单独标注】。原始课件：第三章-dw(3).pdf

一、编程模型：两个分类维度

1.1 依据程序结构分类

类型课件定义
非模块化编程应用程序作为一个整体来进行设计、测试和调试
模块化编程强调将程序的功能分离为独立的、可互换的模块，每个模块执行某一具体功能。又分两层：编码层面的模块化（如 TinyOS 组件化编程）、二进制层面的模块化（如 SOS 模块化编程）

TinyOS 与 SOS 的关键区别（必背）：

对比TinyOS 组件化编程SOS 模块化编程
应用构成应用由多个组件组合而成应用由多个模块组成
编译后单个二进制程序映像，不再保留组件化的信息仍有模块信息，可动态加载
// SOS 模块头部的例子（课件原文节选） static const mod_header_t mod_header SOS_MODULE_HEADER = { .mod_id = SURGE_MOD_PID, // 模块的ID为SURGE_MOD_PID .state_size = sizeof(surge_state_t), .num_sub_func = 1, // 订阅服务的个数 .num_prov_func = 0, .platform_type = HW_TYPE, // or PLATFORM_ANY .processor_type = MCU_TYPE, .module_handler = surge_module_handler, };

1.2 依据执行逻辑分类

基于事件驱动的编程

应用程序会实时地处理或响应系统中的事件；应用程序由多个事件处理函数构成。课件例子：周期性采集传感器读数并无线发送——计时完成事件 → 读传感器 → 读数完成事件 → 提交传输任务 → 传输完成事件（若未成功则继续提交任务）。

基于多线程的编程

一个线程对应一个逻辑上的任务。教材 PPT 补充：能更好地组织程序结构、代码可读性更高，减少由代码分片带来的额外代码量。课件例子：发送线程在一个 while(TRUE) 循环里顺序读温度、湿度、光照，打包发送后休眠。

教材 PPT 补充：事件模型的特点

基于事件的编程模型可以较好地保证系统的实时性和响应性。

课后习题 3 复算：读一个传感器平均 3ms，发送 6ms。 事件驱动：3 个传感器读取可并发进行 → t1 = 3ms + 6ms = 9ms 多线程：3 个传感器顺序读取 → t2 = 3+3+3+6 = 15ms 结论（习题答案原文）：事件驱动下读取可并发、性能更高。

二、调度方式：四种（必背定义）

方式课件定义
抢占式高优先级线程会抢占低优先级线程的执行
非抢占式系统一旦把处理器分配给就绪队列中的某线程后，该线程便一直执行下去，直至完成或阻塞
协作式只有在线程主动交出 CPU 的控制权（yield()）后，才可以让其他线程得到 CPU 控制权
时间片轮转系统默认给每个线程分配相同时间片，时间片用完即使任务未完成也必须交出 CPU

2.1 调度方式对原子操作的影响（必考代码题）

问题：多个线程同时对共享变量 x 有操作权限，如何进行原子操作，使 x 在 RAM 与外存之间始终保持一致？课件给出的三种写法：

非抢占式： { x++; Yield(); write(x); } ← 中间 Yield() 错误！ 协作式： { x++; write(x); Yield(); } ← 末尾 Yield() 正确 抢占式或时间片轮转：需加互斥锁 mutex m; m.lock(); { x++; write(x); } m.unlock();

课件思考题 1（本课核心，三问全解）

三个线程 a、b、c，单独执行完的时间分别为 10s、20s、30s。

（1）非抢占式：时间点 0s 时 a,b,c 顺序启动，三个线程完成时间分别是多少？

点开看参考答案

非抢占式下单个线程依次执行完，各自花费的时间分别为 10s、20s、30s（课后习题答案原文）。

（2）抢占式：优先级 c>b>a，a、b、c 的就绪时间点分别为第 1s、第 2s、第 15s，完成时间？

点开看参考答案

课件未给出此问（纯抢占式版本）的标准答案，建议向老师确认。课后习题答案给的是它的变体——"协同式和抢占式并存，b 执行完 4s 有 yield() 指令"版本：a 先执行完，花费时间为 1s+4s+9s=14s；紧接着 c 执行完，花费的时间为 30s；最后 b 执行完，花费的时间为 59s（可画甘特图计算）。

（3）时间片轮转：时间片 10s，a、b、c 启动时间点分别为第 0s、第 10s、第 20s，完成时间？

点开看参考答案

按课后习题答案原文：a 先执行完，花费的时间为 10s；紧接着 b 执行完，花费的时间为 30s；最后 c 执行完，花费的时间为 40s。

课后习题 4：调度方式图中，图 (a) 哪几行代码会被抢占、图 (b) 哪几行会被抢占？（习题答案：图 a 为 5、6、7 行；图 b 为 1、2、3、4 行。注：该题原图未在提取文本中给出，作答时请对照教材原书图形。）
