一、模型压缩与量化的基本概念

模型压缩（课件第 27 页）：减少模型大小与复杂度，使其能在资源受限设备上部署运行。端侧智能（微型机器学习）需将深度学习模型部署到数十亿物联网设备上，模型压缩是其中的关键支撑技术。核心技术：量化、剪枝、蒸馏、算子分割、神经架构搜索（NAS）等。

方法改变什么主要作用限制与代价
量化降低权重／激活的表示精度（FP16、INT8、4 bit）减小权重体积与访存量，适配硬件上可能加速可能精度损失，收益依赖量化方案和算子实现
剪枝移除低贡献权重、通道或其他结构单元减少有效参数与计算，结构化剪枝更易实际加速通常需微调恢复精度，非结构化稀疏依赖硬件支持
知识蒸馏用教师的输出或特征指导较小的学生模型把部分能力迁移给小模型，降低部署成本增加训练或数据生成成本，学生能力受容量和数据限制
云边协同调整任务在端、边、云之间的执行位置与分工利用远端算力处理复杂任务，减轻终端负担依赖网络时延和连接状态，需考虑传输开销与数据隐私
必背结论

量化、剪枝、蒸馏属于模型层优化；云边协同属于系统部署优化，两者可以组合使用。

量化定义（第 29–30 页）：通过降低参数数值精度（如 FP32 → INT8），减小模型大小、降低内存占用，并可能加速计算。本质：为高精度浮点数与低精度整数之间建立精确的映射关系。直观类比：像把高清照片（FP32）压缩成高质量 JPEG（INT8）——文件变小了，但关键信息基本保留。

二、量化原理：Scale、零点与 MinMax

两个关键参数（第 31 页）

缩放因子 Scale（S）：正实数，定义量化器步长（每个整数步长对应的浮点区间大小），可理解为浮点与整数世界间的「汇率」。
零点 Zero Point（Z）：整数，确保浮点数中的 0 被精确映射到量化空间，对非对称分布数据（如 ReLU 激活值）至关重要。

MinMax 线性量化求解（第 32 页）

x_max＝输入浮点数据最大值；x_min＝最小值；q_max＝最大定点值（127 / 255）；q_min＝最小定点值（−128 / 0）。
量化过程用 RTN（Round-to-Nearest，四舍五入），zero_point 与量化值需截断到 [qmin, qmax] 内。课件示例：FP32 [3.0, −5.5, 0.0, 6.0, −6.0, 2.5] → INT8 [64, −117, 0, 127, −128, 53]。

三、量化分类：线性／非线性、对称／非对称

线性 vs 非线性（第 34–35 页）

按浮点值与量化值的映射关系是否均匀划分。线性量化简单高效、易于硬件实现，是业界主流。非线性量化（映射不等距）主要类型：① 对数量化（量化级数按指数分布，乘法转加法，应用于海思 351X 等专用 AI 芯片）；② 聚类量化（K-Means 找中心点作 Codebook，精度高但推理需查表）；③ 可学习量化（量化电平作为可学习参数，梯度下降自动调整）。

对称 vs 非对称（第 36–37 页）

对称量化：零点固定为 0，[-|max|,|max|]→[-127,127]（−128 保留不用以维持对称）。算法简单、计算开销最低；缺点是数据分布偏斜时浪费位宽。常用于对权重量化（PyTorch 动态量化、ONNX 量化常用）。
非对称量化：引入零点 Z，[min,max]→[0,255] 或 [-128,127]。位宽利用充分、精度更高，特别适合 ReLU 后的非负激活值；需额外计算和存储零点。常用于对激活值量化（如 Google Gemmlowp 库）。

四、量化方式：PTQ（动态／静态）与 QAT

特性维度动态量化静态量化QAT（量化感知训练）
做法仅离线量化权重，激活值在推理时实时量化（每层实时算 scale 和 zero_point）权重与激活值均离线量化，用校准数据集预计算固定 scale / zero_point训练/微调阶段插入「伪量化」节点模拟舍入误差，让模型感知量化影响并主动调整权重

校准数据无需需代表性校准集无需（训练中感知）
推理速度一般最快最快
精度较高较高最高
适用场景Transformer/RNN 等（权重固定、激活范围动态变化）CNN 等固定结构（MobileNet 的标准量化方案）精度要求极高场景
课件总结句（必背）

追求快速部署用动态量化，追求推理速度用静态量化，追求极致精度用 QAT。

要点补充：① 动态量化中，INT8 相乘可能溢出，需用 INT32 累加器存中间结果，再反量化回 FP32；PyTorch 的 torch.quantization.quantize_dynamic 官方仅支持 nn.Linear、nn.LSTM、nn.LSTMCell、nn.GRU、nn.GRUCell，不支持 nn.Conv2d（卷积层激活值数据量大，实时量化开销甚至抵消 INT8 加速）。AlexNet 动态量化实例：精度不变，模型大小 55.67MB→16.65MB，但推理速度提升有限（约 241→250 张/秒）。② 静态量化的校准（Calibration）：用代表性数据跑 FP32 模型 → 统计每层激活值范围 → 预先确定 scale / zero_point → 推理时 INT32 结果直接转 INT8，无需 FP32 中转；AlexNet 实例中 100–200 张校准图就够，实现「存储与显存真压缩、推理真加速」。

五、大模型量化：RTN 失效与 LLM.int8()

方法一：RTN 四舍五入（第 50 页）

核心思想：权重经缩放后直接四舍五入到最近整数 Q = round(W/scale) + Z。Data-free 特性：权重量化完全不依赖数据，应用快速廉价（PyTorch 量化默认使用）。局限：模型规模跨越临界点时这种简单方法会失效。

失效原因：异常值（第 51–52 页）

当模型规模超过约 60 亿（6B）参数时，传统 8 位量化性能急剧下降。大模型存在数值极大（比普通值大 20 倍以上）的稀疏特征维度，对性能至关重要：巨大异常值拉宽 [min,max] → scale 变得非常大 → 正常值 W 除以巨大 scale 后趋近 0 → 精度信息被抹平。异常值仅占约 0.1% 输入特征，但将其置零会导致困惑度上升 600–1000%。

经典方法：LLM.int8()（第 53–56 页）

思路：对 99.9% 的常规值使用高效的 8 位计算，同时为 0.1% 的关键异常值保留高精度（FP16）。
① 向量级量化（Vector-wise）：不再为整个矩阵用一个缩放常数，输入矩阵每一行、权重矩阵每一列各用独立缩放常数，把离群值影响限制在单个行/列内；
② 混合精度分解三步：识别（找到含离群值如绝对值>6.0 的特征维度）→ 分离（把矩阵乘法 XW 拆成异常值部分和常规部分）→ 合并（两部分结果相加）。
结论：LLM.int8() 在将模型内存减半的同时，保持了与 16 位浮点数完全相同的性能。

量化效果实例（第 58 页，DeepSeek-R1-Distill-Qwen-7B 的 GGUF 对比）：F16 15.24 GB（100%）→ Q8_0 8.10 GB（约 53%）→ Q4_K_M 4.68 GB（约 31%，存储体积减少约 69%）。注意：课件提醒完整版 DeepSeek-R1 总参数 671B，硬件需求不能用本例推断；4.68 GB 是文件体积，判断能否部署须在目标设备、目标上下文长度下验证（运行内存 ≈ 权重 + KV Cache + 激活/工作区 + 框架开销）。
