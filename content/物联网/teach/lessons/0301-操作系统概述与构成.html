操作系统概述与构成

一句话：物联网操作系统是什么、跟传统操作系统差在哪、由哪些组件构成——本章一切内容的起点，也是名词解释高频考点。

本课依据

考试内容以 PPT（课件）为准。本课对应课件《第三章-dw(3)》"概述"节【教材 PPT 补充部分会单独标注】。原始课件：第三章-dw(3).pdf

一、物联网操作系统的定义与作用

课件原文要点：物联网操作系统是支撑物联网大规模发展的核心软件。它屏蔽了物联网硬件开发的差异性，提供了统一的编程接口，为多个应用的执行提供了运行时环境，降低了物联网应用开发的成本和时间。硬件抽象是操作系统核心功能之一。发展现状八个字：数量众多、百家争鸣。

教材 PPT 补充：为什么要统一接口

开发者可以基于统一的操作系统建立庞大的应用生态——这对物联网操作系统尤为重要；同时为物联网的统一管理奠定基础。教材 PPT 列举的代表：谷歌（Android Things）、微软（Windows 10 IoT Core）、ARM（mbed OS）、阿里巴巴（AliOS Things）、华为（HarmonyOS）。

二、与传统操作系统的三大区别（必考）

区别点课件结论
存储空间占用不同物联网操作系统内存占用较小，一般只有几十 KB
内存管理方式不同有 MMU vs. 无 MMU
OS 特权模式不同很多物联网芯片不具有 CPU 特权模式，所有的指令都能访问任何硬件资源 → 有 Bug 的程序可以在不受操作系统的控制下轻松地占用 CPU 周期
教材 PPT 补充：MMU 与特权模式的细节

传统操作系统一般运行在具有 MMU（内存管理单元）的设备上，能提供地址翻译和内存保护功能；物联网操作系统因设备而异——缺乏 MMU 时难以提供这两种功能，具备 MMU 时可提供轻量级的地址翻译和内存保护。传统操作系统一般运行在具有特权模式的 CPU 上；由于缺乏 CPU 特权模式，物联网操作系统很难解决控制冒险（Control hazards）问题，可能导致传感器节点没有响应。

课后习题答案补充：具体数字（可当论据背）

Linux 内存占用可达几百 MB、Windows 甚至几 GB；对比：TinyOS 2.x 最小数据内存只有 2KB、最小程序闪存可达 17KB；AliOS-Things 最小数据内存可达 20KB、最小程序闪存可达 40KB。习题答案把区别归纳为四方面（数量/存储/内存管理/特权模式），并把作用归纳为四条：①屏蔽物联网碎片化特征、提供统一编程接口；②培育物联网生态环境；③降低开发成本和时间；④为物联网统一管理奠定基础。

四、两个重要概念（名词解释高频）

Library OS（库操作系统）

将操作系统的某些功能作为库而不是作为一个单独的内核运行。应用程序直接调用操作系统服务，而不是通过系统调用接口。好处：减少用户态和内核态之间的上下文切换、提高性能，并可为特定应用程序定制操作系统功能。

微内核 vs 宏内核

微内核（Microkernel）：只提供最基本核心功能——任务/线程管理、内存管理和进程间通信（IPC）；其他服务（文件系统、设备驱动、网络协议等）作为用户态进程运行，通过消息传递与微内核通信 → 高度模块化和灵活，服务和驱动可独立添加、更新或替换。宏内核（Monolithic Kernel）：把许多功能集成在一个大型的内核态进程中，例如 Linux。

思考题 / 课后习题（本课相关）

课后习题 1：物联网操作系统与传统操作系统的不同，有什么作用？（课件思考题同款）

点开看参考答案

不同体现在四方面：①操作系统类型数量不同——传统平台基本统一（PC 端 Windows/Linux，手机端 iOS/Android），物联网操作系统仍百家争鸣（Android Things、Windows 10 IoT Core、mbed OS、AliOS-Things、Huawei-LiteOS 等），未建立统一应用生态，移植性较差；②存储空间占用不同——传统 OS 内存占用大（Linux 几百 MB、Windows 几 GB），物联网 OS 一般只有几十 KB（TinyOS 2.x 最小数据内存 2KB、程序闪存 17KB；AliOS-Things 最小数据内存 20KB、程序闪存 40KB），可节省内存资源、提高运行效率；③内存管理方式不同——传统 OS 运行在具有 MMU 的设备上、能提供地址翻译和内存保护，物联网 OS 运行在缺乏 MMU 的设备上时难以提供，可能带来安全问题和运行效率问题；④OS 特权模式不同——传统 OS 运行在有特权模式的 CPU 上、可保护硬件资源安全，物联网芯片多无特权模式、所有指令都能访问任何硬件资源，提高可扩展性但可能有安全问题。

作用有四条：屏蔽物联网碎片化特征、提供统一编程接口；培育物联网生态环境；降低物联网应用开发的成本和时间；为物联网统一管理奠定基础。（课后习题答案原文）
