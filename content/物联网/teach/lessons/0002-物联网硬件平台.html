三、关键特性 2：功耗/能耗（必会计算）

物联网节点一般周期性采集并上报数据，其余大部分时间处于休眠状态以延长生命周期——所以功耗越低，运行时间越长。每个模块（如计算模块、通信模块）的功耗：

ΔE = Σ (i = 1 → n) Δtᵢ · Iᵢ · pᵢ n ：模块能耗状态的数量 Δtᵢ ：模块在能耗状态 i 下的工作时间 pᵢ ：模块在能耗状态 i 下的功率 Iᵢ ：指示变量。Δtᵢ > 0 时 Iᵢ = 1；Δtᵢ = 0 时 Iᵢ = 0

课件例题（一步步照做）：使用 Arduino UNO，电压保持 5V 不变，运行 1s，其中 0.5s 休眠、0.5s 工作：

i=1 睡眠：p₁ = 0.1μA × 5V = 5 × 10⁻⁷ W i=2 工作：p₂ = 0.2mA × 5V = 1 × 10⁻³ W ΔE = 0.5s×1×5×10⁻⁷ + 0.5s×1×1×10⁻³ = 0.50025 × 10⁻³ J

四、关键特性 3：运算速度和内存大小

  • 运算速度一般用 CPU 主频来描述。

五、关键特性 4：接口类型

5.1 物理接口：引脚 vs Grove port

引脚

通过杜邦线连接，过程复杂且易出错；引脚接错可能导致程序无法工作，甚至烧坏外设和主板。

连接套接口 / Grove port

通过 Grove port 线连接，外设接入容易、快速且不易出错。

5.2 通信协议：常见 6 种

协议课件定义（背）
模拟信号 Analog使用模拟量表示数据的信号，需要 ADC 转化（处理器不能直接解析）
数字信号 Digital使用序列离散值表示数据的信号
PWM基于数字信号的脉冲调制技术
UART用于异步逐位传输数据的全双工通信接口标准
I2CPhillips 公司推出的高性能串行总线
SPI高速、全双工、同步的通信总线

教材 PPT 补充的关键细节：

  • Digital 编码方式：不归零编码（NRZ）、归零编码（RZ）、曼彻斯特编码、差分曼彻斯特编码。
  • PWM 两要素：频率（决定信号周期）+ 占空比（决定单个周期内高电平持续时间）；用途：控制 LED 灯或电机功率，降低能耗。
  • UART：全双工 = 同一时刻用 RX、TX 两个引脚分别收发；异步 = 无时钟同步，收发方规定好数据位长和波特率即可通信。
  • I2C：两根线——SDA 数据线 + SCL 时钟线；半双工（同一时刻 SDA 只有一个方向），总线调度先来先服务；地址字节高 7 位是从设备地址、最低位是方向（"0"写、"1"读）；速率 100k / 400k / 1M / 3.4M bps，最大长度 7.62m，支持 127 个设备。
  • SPI：两根数据线 MISO、MOSI 允许双向通信；配置复杂——控制寄存器配置工作模式、波特率寄存器配置传输率。

5.3 UART 缓存计算（课件例题 + 思考题 2）

每次 UART 传输 11 位 = 8 数据位 + 2 标识位 + 1 校验位 课件例（波特率 B=9600，中断处理 1ms，缓存只存数据位）： 传输 1 位时间 = 1/B 中断时间内到达的数据 = (1/1000) / (1/B) = B/1000 位 数据位 = B/1000 × 8/11 缓存字节 = B/1000 × 8/11 / 8 = B/11000 → 向上取整 1 字节 思考题 2（中断 2ms）：2 × B/11000 = 2×9600/11000 ≈ 1.745 → 向上取整 2 字节（习题答案一致）

6.2 STM32 平台

ST（意法半导体，1987 年由意大利 SGS 微电子与法国 Thomson 半导体合并而成）推出的 ARM Cortex-M 内核单片机：内核有 Cortex-M0、M3、M4、M7，每个内核又分主流、高性能、低功耗三个档。

名词解释：CPU / MCU / MPU（课件原文）

CPU：Central Processing Unit，计算机系统的运算和控制核心，信息处理、程序运行的最终执行单元。
MCU：Micro Controller Unit，把 CPU、内存、I/O 接口和时钟电路等基本组件集成在一个芯片上；通常设计为低功耗设备，适合长时间运行和电池供电。
MPU：Micro Processing Unit，相比 MCU 更侧重高性能计算和复杂任务处理，时钟速度更高、内存更大、计算能力更强。

  • 开发板组成：主控芯片、USB 电源、扩展接口、电源接口、下载接口、复位按键。
  • 三种低功耗模式（必背）：睡眠——内核停止运行、外设保持运行，适合等待外设中断时降功耗；停机——所有时钟停止，约 20μA；待机——功耗最低，约 2μA，关闭所有时钟并完全关闭 1.2V 区域电源。
  • 接口数量：STM32F103C8T6 — Digital 32 / PWM 6 / UART 3 / I2C 2 / SPI 2；STM32F103VET6 — 100 / 14 / 3 / 2 / 2。
  • 常见开发板：STM32 最小系统板（C8T6/72MHz，64/20KB，53×23mm，5V）；野火指南者（VET6，512/64KB，130×100mm）；正点原子精英（ZET6，512/64KB，115×117mm）。
  • 主要特点：开发方便（库文件开发、程序模块化，一个串口即可烧写）；丰富通信接口（I2C、USART、SPI、CAN、USB 2.0 全速）；调试简单（20 脚 JTAG + 针对 Cortex-M3 的 SWD 串行单线调试）；低功耗（睡眠/停机/待机三种模式间取得平衡）。

6.3 ESP32 平台

中国乐鑫信息科技（2008 年成立于上海张江，无晶圆厂半导体公司）设计的集成 2.4GHz Wi-Fi 和蓝牙双模的单芯片方案。发展史：2013 ESP8089（平板/机顶盒 Wi-Fi SoC）→ 2014 ESP8266EX（首款物联网 SoC，超低功耗）→ 2016 ESP32（旗舰，Wi-Fi + Bluetooth SoC）→ 2018 Wi-Fi MCU 市场全球领先 → 2023 IoT 芯片全球出货量突破 10 亿颗。

  • CPU/存储：低功耗 Xtensa LX6 32-bit 单/双核处理器，最高 240MHz；片上 448KB ROM + 520KB SRAM。
  • 外设接口：34 个 GPIO、3 组 SPI、2 个 I2C、2 个 I2S、3 个 UART、2 个 12-bit SAR ADC、2 个 8-bit DAC、10 个触摸传感器等。
  • 五种能耗模式（按功耗从高到低）：Active（射频工作）→ Modem-sleep（CPU 运行，Wi-Fi/蓝牙基带和射频关闭）→ Light-sleep（CPU 暂停；RTC 存储器、外设、ULP 协处理器运行，可被定时器/外部中断唤醒）→ Deep-sleep（CPU 和大部分外设掉电）→ Hibernation（内置 8MHz 振荡器和 ULP 协处理器均被禁用）。
  • 主要特点：性能稳定（工作温度 −40°C～+125°C，自校准电路动态电压调整）；高度集成（天线开关、RF balun、功放、低噪放、滤波器、电源管理集于一体）；超低功耗（精细分辨时钟门控、省电模式、动态电压调整）；双模解决方案（可作独立系统，或作主机 MCU 的从设备，经 SPI/SDIO 或 I2C/UART 提供 Wi-Fi 和蓝牙）。

6.5 树莓派平台

树莓派是一款微型计算机，性能几乎和一台计算机相同。发展线：2006 年原型（22.1MHz 的 ATmega 664，整板 25 美元）→ 2011 年集成 HDMI、USB、以太网 → 2012 年二代换 BCM 2836 → 2016 年三代集成 WiFi 和 BLE（BCM 2837）→ 2019 年四代支持 BLE5.0（BCM2711）。

  • 组成：微控制器、扩展接口、USB 电源、SD 卡、HDMI、音频接口、以太网口、USB 接口——接上电源、插上键盘鼠标显示器就能开机办公。
  • 树莓派 4B：1.5GHz、1/2/4/8GB RAM、40 个数字引脚 / 0 个模拟引脚，集成以太网、WiFi、BLE、BLE5.0、HDMI；尺寸 88×58mm。
  • 能耗（5V，按 CPU 负载）：0% 负载 760mA → 单核 100% 900mA → 四核 100% 1200mA；树莓派属于高功耗类型。
  • 盾板：GrovePi+ 让原本不支持 Analog 外设的树莓派可以接入 Analog 外设——它通过 I2C 与树莓派通信，Analog 类型 Grove port 收到的传感数据经 I2C 转发给树莓派（兼容树莓派 2/3/4/Zero）；另有 Grove Base HAT（兼容 2/3/4）。
  • 主要特点：开发简单（支持 C、Python、JavaScript 等跨平台高级语言）；上手容易（就是一台微型计算机）；功能强大（Cortex-A 高频 MCU，主频可达 1.5GHz、最高 8GB 内存，HDMI/USB/AV/以太网等接口堪比普通计算机）。

6.6 Jetson 平台

NVIDIA 推出的嵌入式 AI 计算平台，主要用于边缘计算和人工智能（AI）应用，已在制造、物流、零售、服务、农业、智慧城市、医疗保健和生命科学领域广泛应用。

名词解释：三个"算力单位"（课件原文）

TOPS：Tera Operations Per Second，1 TOPS = 处理器每秒进行一万亿次（10¹²）操作，通常默认对 INT8 整型数的处理次数。
TFLOPS：每秒万亿次（10¹²）浮点运算（FLOPS = Floating-point Operations Per Second，通常 FP32）。
GFLOPS：每秒十亿次（10⁹）浮点运算数。

7.1 Arduino 版（六步）

  1. 硬件方案：UNO 只包含 MCU 和执行模块 LED，没有集成任何传感模块 → 外接温湿度模块 DHT11（数据引脚接 2 号引脚）。
  2. 开发环境：Arduino IDE（软件库支持、交叉编译、程序烧写、串口通信；支持 Windows / Mac OS / Linux）。
  3. 编程：setup-loop 结构——setup 是程序入口函数，仅执行一次，用于初始化；loop 是循环体，setup 返回后被重复执行。
  4. 交叉编译：工具 → 开发板 → Arduino UNO，单击"验证"。
  5. 烧写程序（USB 连接开发板）。
  6. 测试验证：打开串口，波特率 9600，查看实时数据。
#include "DHT.h" DHT dht(2, DHT11); // DHT11 数据引脚接 2 号引脚 void setup(){ // 初始化，仅执行一次 Serial.begin(9600); // 串口波特率 9600 Bd/s dht.begin(); // 初始化 DHT11 模块 } void loop(){ // 循环体，重复执行 float h = dht.readHumidity(); // 读湿度 float t = dht.readTemperature(); // 读温度 Serial.print("Humidity: "); Serial.println(h); Serial.print("Temperature: "); Serial.println(t); delay(3000); // 每隔 3s 打印一次 }

7.2 树莓派 4B 版

  1. 硬件方案：4B 只包含 MCU 和通信模块（WiFi/BLE/以太网），同样没有传感模块 → 外接 DHT11。
  2. 软件方案：选 Raspbian Stretch with desktop 系统；Linux 下两个常用开源库——WiringPi（GPIO 操作的 C++ 库）与 GrovePi（针对扩展板 GrovePi/GrovePi+ 的软件库，提供驱动和较完整的编程接口，支持 C++/Java/C#/Go/Node.js/Python 等主流语言）。本案例选 GrovePi + Python，通过 SSH 远程登录开发。
  3. 编程（indoorEnv.py）：grovepi.dht(sensor, blue) 读温湿度 → math.isnan() 校验 → 打印 → time.sleep(3)。
  4. 运行 & 测试：python indoorEnv.py，控制台输出 temperature = 27.00 C / humidity = 95.00% 等。

八、研究前沿（两句话 + 两个系统）

高性能

边缘计算、特别是 AI 的发展对处理能力提出更高要求；处理器工艺进步使芯片计算能力增强、功耗降低。（教材 PPT 举例：谷歌 Edge TPU、华为昇腾 310。）

模块化

提高硬件可定制性（选不同模块搭建适合应用的硬件平台）与模块可重用性（避免重复设计相同功能的电路模块）。

课件例子：Signpost（IPSN'18，城市感知节点，模块化组件，用户可方便更换某一模块以匹配应用）；另一工作（SenSys'08）把硬件节点分为控制、供电、存储、通信、传感等模块，模块间用标准数据传输接口连接，按需组装定制。

九、课件思考题（先自己答，再点开对照）

思考题 1（MCU 属性表题）

两块 MCU：Msp430F2618（1.8～3.6V，RAM 8KB，Flash 116KB，工作 0.5mA，睡眠 1.1μA）；Msp430F5437（1.8～3.6V，RAM 16KB，Flash 256KB，工作 0.28mA，睡眠 1.7μA）。电压恒定 3V，给定程序都执行 10s。

问 ①：程序中声明了 char buf[10240]（10240 字节），应该选择哪块 MCU？

点开看问 ① 的答案

数据段存在于 MCU 的 RAM 中。10240 字节 > 8KB（F2618 放不下），≤ 16KB（F5437 满足）→ 选 Msp430F5437。（课后习题答案原解）

问 ②：占空比为 80% 时，谁的能耗低？

点开看问 ② 的答案

80% = 8s 工作 + 2s 睡眠：E(F2618) = 2×3.3×10⁻⁶ + 8×1.5×10⁻³ = 0.012 J；E(F5437) = 2×5.1×10⁻⁶ + 8×0.84×10⁻³ = 0.0067 J → F5437 能耗低（工作占主导，比工作功率）。（课后习题答案原解）

问 ③：占空比为 0.1% 时，谁的能耗低？

点开看问 ③ 的答案

0.1% = 0.01s 工作 + 9.99s 睡眠：E(F2618) = 9.99×3.3×10⁻⁶ + 0.01×1.5×10⁻³ = 4.7967×10⁻⁵ J；E(F5437) = 9.99×5.1×10⁻⁶ + 0.01×0.84×10⁻³ = 5.9349×10⁻⁵ J → F2618 能耗低（睡眠占主导，比睡眠功率）。

结论口诀：占空比高比"工作功率"，占空比低比"睡眠功率"。

思考题 2（UART 缓存）

波特率 9600Bd/s、接收中断处理 2ms，接收缓存应为多少字节？（每次 11 位 = 8 数据 + 2 标识 + 1 校验，缓存只存数据位）

点开看答案

2ms 内到达数据 = 2/1000 ÷ (1/9600) = 19.2 位；数据位 = 19.2 × 8/11 ≈ 13.96 位 ≈ 1.75 字节 → 向上取整 = 2 字节（习题答案第 6 题同款计算，结果一致）。习题还要求画 UART 传"10101"的波形（含起始/结束标志位与校验位）。

思考题 3（九连问，每问独立）

问 1：哪些硬件平台属于 Things 类别？哪些属于 Smart Things 类别？

点开看问 1 的答案

按课件平台分类表：Things 类——传感节点、STM32、ESP32、Arduino；Smart Things 类——树莓派、Jetson。

问 2：RAM 和 Flash 有区别吗？

点开看问 2 的答案

RAM 存数据、易失性；Flash 存程序、非易失性（断电程序仍在）。

问 3：程序声明了 4100 字节的数据，能否运行在 MicaZ 节点上？

点开看问 3 的答案

不能。MicaZ 的 RAM 只有 4KB = 4096 字节 < 4100，数据放不下。

问 4：Atmega 系列处理器属于什么架构？有什么特点？

点开看问 4 的答案

AVR 体系结构——RISC（精简指令集）；存储采用哈佛结构，数据寻址空间与程序寻址空间分离。

问 5：STM32 中一般有几种低功耗模式？哪种功耗最低？

点开看问 5 的答案

3 种：睡眠、停机、待机；待机功耗最低（约 2μA）。

问 6：盾板的功能作用是什么？适用于哪些硬件平台？

点开看问 6 的答案

像盾一样插在主板上，为平台扩展功能和接口；适用 Arduino（Base Shield 等）与树莓派（GrovePi+、Grove Base HAT）。注意：插上盾板后会完全覆盖主板，此时无法再用杜邦线在引脚上接传感器（习题答案第 4 题）。

问 7：ESP32 集成无线模块有哪些？这些无线协议能否同时运行？

点开看问 7 的答案

集成 2.4GHz Wi-Fi + 蓝牙双模（课件原文）。"能否同时运行"课件未给出标准答案，建议向老师确认，勿自行作答。

问 8：Jetson 硬件平台的主要特点是什么？适用于哪些场景？

点开看问 8 的答案

强大计算能力、低功耗设计、高度集成、支持多种 AI 框架；适用于边缘计算与 AI（制造、物流、零售、服务、农业、智慧城市、医疗保健等）。

问 9：1.3 TFLOPS 是什么意思？

点开看问 9 的答案

每秒 1.3 万亿次（10¹²）浮点运算（FLOPS 通常按 FP32 计）。

计算题（习题 7）：以写数据"10101"到 0x0B 设备为例，按步描述 I2C 的传输过程，要求画出传输信号波形。

点开看 I2C 题的答案

主机先发 8 位指令——高 7 位 = 0x0B 的地址、最低位 = 0 表示写；SCL 保持高电平时 SDA 从 1 跳到 0 = 开始传输（总线"忙"），SCL 开始振荡逐位送数据；结束时 SCL 高电平期间 SDA 从 0 跳到 1 = 传输结束（总线"闲"）。考试要求画出 SDA/SCL 波形。

计算题（习题 8）：SPI 传输中，SPPR 和 SPR 分别设置为 010 和 100，总线时钟频率至少为多少才能保证数据传输率为 200Kbps？

点开看 SPI 题的答案

BRD = (SPPR+1) × 2^(SPR+1) = (2+1) × 2⁵ = 96；fBUS = BR × BRD = 200K × 96 = 19.2MHz。
