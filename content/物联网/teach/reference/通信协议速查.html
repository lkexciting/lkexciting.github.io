六、必背指标清单（30 秒自测）

  • 802.15.4 物理层：4bit→32 码片；chip rate 2M/s → data rate 250kb/s；每码片 1μs，Q 相位偏移 0.5μs；脉冲成形上半正弦=1、下半正弦=0。
  • 链路质量阈值：RSSI>−87dBm→PRR>85%；<−92dBm→PRR<50%；RSSI 经验 −95~−55dBm；SNR 经验 3~43dB（Noise Floor ≈−98dBm）；LQI 50~110、CTP 中 >105 高质量。
  • LPL：CCA 阈值默认 −77dBm；广播 Ttrain≥Tsleep；广播开销≈单播两倍；RSSI 特征区分错误唤醒（ZigBee 广播时间 [576,4256]μs、峰均比 ≤1.3）。
  • BLE：广播 AA=0x8E89BED6；CRC 多项式 x²⁴+x¹⁰+x⁹+x⁶+x⁴+x³+x¹+x⁰；白化 7bit；Connection Interval 7.5ms~4s（1.25ms 倍数）；跳频 slot 0.625ms；GATT 服务以 UUID=0x2800 起止。
  • 蓝牙 5.0 三更新：2M PHY（2Mbps）· LE Coded（S=2→500kbps，S=8→125kbps）· 扩展广播（ADV_EXT_IND→AUX_ADV_IND）；5.1 厘米级测向 / 5.2 EATT / 5.3 连接降级。
  • 6LoWPAN：802.15.4 有效负载 80~100B vs IPv6 MTU 1280B → 分段重组 + 头部压缩；IPv6 头 40B、UDP 头 8B、地址共 32B。
  • CTP/RPL：ETX=1/(df·dr)；路径 ETX=Σ 链路 ETX；CTP 数据帧字段 P/C/THL/ETX/Origin/SeqNo；RPL 用 DODAG、DIO（上行）/DAO（下行）、Rank 最低最优。
  • NB-IoT 物理层：NPSS 子帧#5/10ms · NSSS 偶帧#9/20ms · NPBCH 子帧#0；slot 0.5ms（下行）/2ms（3.75kHz 上行 NB-slot）；NPBCH→MIB-NB。
  • NB-IoT 随机接入：Msg1 preamble（single-tone 3.75kHz 跳频，开环功控，步长 {0,2,4,6}dB）→ Msg2 RAR → Msg3 调度传输 → Msg4 竞争解决。
  • LoRaWAN：纯 ALOHA + 1% duty cycle；Class A RxDelay 1s/2s、窗口至少 5 个 symbol、确认上行重传 [1,15] 次；Class B beacon 周期 128s、2 小时无 beacon 回 A；Class C 常开接收。

七、常考计算模板（带出处）

① dBm 换算：D = 10·lg P(mW)；1mW=0dBm，100mW=20dBm（课件 TIPS） ② 占空比平均功耗：0.1%×10mW + 99.9%×10μW = 19.99μW（课件例题） ③ 最远通信距离：PL(d)=PL0+10n·lg(d/d0)+Xσ，令 RSSI=灵敏度 0dBm/−85dBm/PL0=28.5/n=3 → 76.4m（课件例） 1mW/−90dBm/PL0=28.5/n=3 → 112.2m（习题四-1） ④ 实际数据率：η = l/(W·R/8+H+l)，Rreal=ηR H=13B、l=30B、W=5ms、R=250kbps → 37.6Kbps（习题四-2） ⑤ LPL 探测包间隔：n≥210 → 传 5.8ms/11ms → (11−5.8)/2 = 2.6ms（习题四-4） ⑥ EWMA（α=0.9，W=3）：0.67×0.9+0.33×0.1=0.636；0.67×0.9+0.636×0.1=0.667（习题四-5） ⑦ ETX：链路 =1/(df·dr)；路径 = Σ；路径 PRR = 1×0.01 = 0.01（习题四-6/7） ⑧ 重传增益：10·lg1024 ≈ 30.1dB（习题五-2） ⑨ PSD：3.75kHz vs 15kHz → 15/3.75 = 4 倍（习题五-4） ⑩ 链路预算：LoRa 20−(−142)=162dB；比 GPRS 144dB 多 18dB → 10^1.8 ≈ 63 倍（习题五-6） ⑪ LoRa 符号：SF=10、BW=125kHz → Ts=8.192ms；偏移 50/2^10（频移量 ≈6.1035）（习题五-7） ⑫ 网关容量：SX1301 = 8×232.6% = 18.6 × SX1276/8（习题五-8）； 系统容量 (12+13)×8/600≈0.33bps → 250/0.33×8×232.6% ≈ 14096（习题五-9） ⑬ NB-IoT 小区容量：小区面积×住户密度×每户设备数 → ≈52547 个（习题五-3） ⑭ 维特比解码：收到 [00 10 01 01] → u=[0 1 1 0]，V=[00 11 01 01]（习题五-5） ⑮ 802.15.4 调制：10111110 → I：01000101111010101010010001011110 Q：10001111010010010110011100001011（习题四-3）
