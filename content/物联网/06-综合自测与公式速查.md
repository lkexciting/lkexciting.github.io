> 先做题，再展开答案。难度分配用于复习组织，并非对考试分值的预测。例题的详细过程见对应章节，下面混合原题与教学改编题。

## 1. 公式速查

| 题型 | 公式 | 最容易错的地方 |
|---|---|---|
| 功率 | $P=VI$ | μA 与 mA 统一 |
| 多状态能量 | $E=\sum V_iI_i\Delta t_i$ | 能量 J、功率 W |
| 平均电流 | $I_{avg}=DI_a+(1-D)I_s$ | D=1% 要代 0.01 |
| 电池寿命 | $T=C/I_{avg}$ | mAh/mA 得 h |
| UART 缓存 | $N\ge\lceil Bt/L\rceil$ | L 为每帧总 bit，t 用 s |
| 指令速率 | $R=f/k$ | 主频不等于指令数 |
| 权重体积 | $M=N_{param}b/8$ | bit 转 Byte，另算运行内存 |
| 卷积参数 | $K_hK_wC_{in}C_{out}$ | 偏置另算 |
| 卷积 MACs | $H_oW_oK_hK_wC_{in}C_{out}$ | 输出高宽；分组卷积需调整 |
| 量化 | $q=clip(round(x/S)+Z)$ | 舍入、截断、范围约定 |
| 反量化 | $\hat x=S(q-Z)$ | 不是直接 q×S 后忘零点 |
| Precision / Recall | $TP/(TP+FP)$ / $TP/(TP+FN)$ | 分母分别是预测正/真实正 |
| F1 | $2TP/(2TP+FP+FN)$ | 不是算术平均 |
| 能量/次 | $E=P_{avg}T$ | ms 转 s |
| EWMA | $p'=\alpha p_{current}+(1-\alpha)p_{old}$ | α 对应谁 |
| ETX | $1/(d_fd_r)$ | 考虑 ACK 成功，前提需说明 |
| 路径成本 | $Cost(v)+ETX(u,v)$ | 不是只选本地最强 RSSI |
| dBm | $10\log_{10}(P_{mW})$ | 与 dB 比值不同 |
| 理想重复增益 | $10\log_{10}N$ dB | 理想近似，不是保证 |
| LoRa 符号时间 | $2^{SF}/BW$ | BW 用 Hz |
| 占空比等待 | $T_{off}\ge T_{on}(1/D-1)$ | 等待与总周期不同 |

## 2. 基础概念题（建议每题 1–3 分钟）

1. 典型物联网四部分分别是什么？网关一定独立存在吗？
2. 原始传感器与虚拟传感器有什么区别？
3. RAM 足够、Flash 不够与 Flash 足够、RAM 不够，分别可能出现什么问题？
4. MCU、开发板、盾板是什么关系？
5. 非抢占式是否意味着完全不需要共享数据保护？
6. 分阶段 I/O 返回成功，是否表示报文已送到？
7. 为什么 Protothreads 跨等待点的变量通常需要 static？
8. 量化、剪枝、蒸馏各改变什么？
9. 6LoWPAN、RPL、Thread、Matter 各解决什么问题？
10. BLE central/peripheral 与 GATT client/server 是不是同一组角色？
11. Friend 与 Relay 能否画等号？
12. LoRa 与 LoRaWAN 是不是同一层协议？

<details><summary>展开概念题参考答案</summary>

1. 设备、网关/网络、云平台、客户端；可直连网络或将网关职责集成。
2. 前者测物理量，后者用算法/模型把已有数据转换为语义状态。
3. 前者固件放不下；后者运行数据、栈或缓冲放不下。两者不能相互替代。
4. MCU 是主控芯片；开发板加上电源、引脚等电路；盾板扩展功能。
5. 不是，中断、多核或主动阻塞等仍可能影响一致性。
6. 不一定，可能仅接受请求，需完成事件或更高层确认。
7. 共享栈、等待时返回调度器，普通自动变量不能可靠跨等待保留。
8. 数值表示；参数/结构；训练监督与学生能力迁移。
9. IPv6 适配；低功耗有损网路由；IPv6 Mesh 组网；应用互操作。
10. 不是，一个是连接角色，一个是属性服务访问角色。
11. 不能；Friend 缓存低功耗朋友消息，Relay 转发 Mesh 消息，可独立配置。
12. 不是，LoRa 主要是 PHY，LoRaWAN 是网络/MAC 等协议体系。

</details>

## 3. 计算题（先写公式和单位）

### 题 13：电池寿命

2800 mAh，工作 20 mA、休眠 0.5 mA、占空比 1%，求理想寿命。若每天自放电为初始容量的 0.5%，再求寿命。

<details><summary>答案</summary>

$I_{avg}=0.695$ mA；寿命约 4028.78 h=167.87 天。自放电每天 14 mAh，等效 0.58333 mA；寿命约 2190.35 h=91.26 天。对应第一章 。

</details>

### 题 14：UART 缓冲

UART 波特率 9600，每帧 11 bit、其中数据 8 bit。最长 2 ms 不能及时排空缓存，按本节约定简化模型至少缓存多少数据字节？

<details><summary>答案</summary>

$\lceil9600\times0.002/11\rceil=2$ B。不是把 9600×0.002 直接当字节。真实持续流还要确认平均消费速率。对应第二章 。

</details>

### 题 15：功率与能量

5 V，0.5 s 工作电流 0.2 mA，0.5 s 休眠电流 0.1 μA，求总能量和平均功率。

<details><summary>答案</summary>

E=0.50025 mJ；总时长 1 s，所以平均功率 0.50025 mW。对应第二章 。

</details>

### 题 16：抢占式调度

a、b、c 分别需要 10、20、30 s；分别在 1、2、15 s 就绪；优先级 c>b>a。求完成时刻。

<details><summary>答案</summary>

a 先运行 1 s；b 运行 13 s；c 在 45 s 完成；b 继续 7 s，在 52 s 完成；a 再运行 9 s，在 61 s 完成。按 a,b,c 为 61、52、45 s。对应第三章 。

</details>

### 题 17：差分更新

旧 `ABCDEACBC`，新 `WABCDEACBCXDEACB`。COPY 固定 5 B，ADD n 固定头 3 B 加 n B 内容。给出一种补丁及大小，并与完整文件比较。

<details><summary>答案</summary>

`ADD 1 W; COPY 9 0; ADD 1 X; COPY 5 3`，共 18 B；完整新文件只有 16 B，所以本小例差分并不省流量。对应第三章 。

</details>

### 题 18：模型权重与内存

100M 参数，FP32 转 INT8，理想权重各多大？是否意味着运行内存同样缩小四倍？

<details><summary>答案</summary>

400 MB→100 MB。运行内存还包括激活、缓存、工作区和框架，不能保证缩小四倍。对应第四章 。

</details>

### 题 19：卷积计算

输出 16×16，3×3 卷积，输入通道 8、输出通道 16，不计偏置。求参数、MACs、FLOPs（1 MAC=2 FLOPs）。

<details><summary>答案</summary>

参数 3×3×8×16=1152；MACs=16×16×1152=294912；FLOPs=589824。公式对应第四章 。

</details>

### 题 20：量化与反量化

S=0.1，Z=3，整数范围 [-128,127]，x=1.24，求 q、反量化值与误差。

<details><summary>答案</summary>

q=round(12.4)+3=15；反量化 0.1×(15−3)=1.2；反量化值减原值=-0.04，绝对误差 0.04。对应第四章 原理。

</details>

### 题 21：分类指标

TP=40、FP=10、FN=20、TN=130，求 Accuracy、Precision、Recall、F1。

<details><summary>答案</summary>

Accuracy=170/200=85%；Precision=40/50=80%；Recall=40/60≈66.67%；F1=80/110≈72.73%。对应第四章 。

</details>

### 题 22：链路质量与路径

某链路数据成功率 0.8、ACK 成功率 0.9，求 ETX。旧 PRR=0.6，新窗口 PRR=0.9，α=0.8，求 EWMA。

<details><summary>答案</summary>

ETX≈1/0.72=1.3889；EWMA=0.8×0.9+0.2×0.6=0.84。ETX 采用独立、稳定、可重试模型。对应第五章 及路由成本原理。

</details>

### 题 23：卷积编码与纠错

按第五章状态表，初态 00，收到 `00 10 01 01`，无末态限制，Viterbi 最可能输入与编码输出是什么？

<details><summary>答案</summary>

输入 0110；编码 00 11 01 01；汉明距离 1。需根据状态转移累计代价并回溯，不能逐组独立纠错。对应第五章 。

</details>

### 题 24：LoRa 与占空比

SF=8，BW=125 kHz，符号时间多少？发送 0.5 s，题设占空比 1%，最少等多久再发？

<details><summary>答案</summary>

符号时间 2.048 ms。总周期至少 50 s，等待至少 49.5 s。对应第五章 CSS 原理与 的占空比例子。

</details>

## 4. 综合设计题（建议每题 8–12 分钟）

### 题 25：室内温湿度监测

每 3 秒采集一次，手机查询，电池供电。写出硬件、任务、通信与验证方案。

<details><summary>参考答题框架</summary>

明确传感器量程和精度；选择 RAM/Flash 足够、接口匹配的 MCU；定时唤醒采样、过滤异常、缓存结果，处理完成后睡眠；短距离手机交互可分析 BLE/GATT；按实际工作与休眠电流算寿命；验证读数、手机断连重连、无效数据、峰值电流与整板漏电。若要远程查询，补上网关/云平台。

</details>

### 题 26：加速度防盗

100 Hz 采样、10 点窗口、每秒判断方差。如何分析检测盲点和代码风险？

<details><summary>参考答题框架</summary>

10 点只覆盖约 0.1 s，不覆盖整秒；短暂振动可能未落在检测时保留的窗口里。应考虑扩大窗口、在线累计或触发检测；保护共享缓冲，处理样本未满、平方和溢出、周期漂移；用环形缓冲降低复制。阈值还需结合采样单位和静态噪声校准。

</details>

### 题 27：模型已经量化但没变快

列出至少四个可能原因，并给验证方法。

<details><summary>参考答题框架</summary>

目标芯片没有高效低精度算子；部分层回退；量化/反量化开销高；模型受访存或预处理限制；batch/线程不同；计时包含加载或未预热。查看实际执行后端和算子，统一配置，分阶段测量延迟、内存与准确率，不能只看文件体积。

</details>

### 题 28：云边分割遇到弱网

网络带宽下降后，如何调整切分并保持服务？

<details><summary>参考答题框架</summary>

建立本地计算+特征传输+网络等待+云计算的时延模型；重新评估每个候选层的特征字节数；常考虑更多本地计算，或压缩特征、降输入、转纯本地降级。不能不看特征尺寸就机械向前/向后移动；同时复核任务质量和数据隐私。

</details>

### 题 29：地下水表上报

每天上报少量数据，偶尔需要配置，NB-IoT 和 LoRaWAN 怎么比较？

<details><summary>参考答题框架</summary>

比较实际地下覆盖、天线、运营商服务/私网维护、峰值发送电流、重传、资费、上报与配置时限。NB-IoT 可采用 PSM/eDRX，但深睡不可即时下行；LoRaWAN Class A 省电，但配置需等上行后窗口。要做现场覆盖测试，而不是只引用标称公里数。

</details>

### 题 30：BLE Mesh 低功耗灯控

一个 Friend 节点没开启 Relay，能否给自己的 LPN 送消息？

<details><summary>参考答案</summary>

可以；Friend 缓存与交付给低功耗朋友属于朋友机制，Relay 是普通消息继续转发能力。需要消息先在允许的 TTL/链路范围到达该 Friend，LPN 再按朋友轮询取消息。对应第五章 。

</details>

## 5. 15 个常见错误：考前快速排查

- 把 mA、mW、mJ 当成同一种量。
- 忘记睡眠电流与电池自放电。
- 把 Flash 容量当成可用 RAM。
- 把 UART 原始 bit 数当成数据字节数。
- 把完成时刻和周转时间混淆。
- 不说明轮转调度同刻入队顺序。
- 把异步发送受理成功当成送达成功。
- 认为 Protothreads 会保存整个栈。
- 认为差分更新一定比整文件小。
- 把权重文件体积当成运行峰值内存。
- 把 FLOPs 减半当成延迟一定减半。
- 把掩码置零当成矩阵结构已缩小。
- 把 6LoWPAN 当路由、Matter 当无线 PHY。
- 把 PSM 的注册保留当成随时可寻呼。
- 把 LoRaWAN Class A 当成随时能接收下行。

## 6. 怎样使用错题结果

每道错题记录“错在概念、公式、单位、假设还是运算”。概念错回对应章节读图；公式错自己推一遍；单位错把每一步量纲写全；假设错先画时间轴或状态图；运算错再用第二种方式核算。不要只把最终答案抄进错题本。
